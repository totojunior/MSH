## 쓰는 법
- 교사 화면(프로젝터)에서 열고 `F`로 전체화면 → `→`/Space/클릭으로 진행합니다. 학생 크롬북용이 아닙니다.
- `←` 이전 · 숫자 화면 이동 · `Home` 처음부터(다음 반, 투표 초기화) · `T` 교사 대본 · `A` 미션 정답 · `S` 출처 · `M` 소리 · `L` 가벼운 모드 · `H` 도움말
- 소리는 첫 입력 뒤에 켜집니다(브라우저 자동 재생 규칙). 교실 스피커로 미리 한 번 들어 보세요.
- 인터넷이 없는 교실: 목록 페이지의 '파일 받기'로 내려받은 HTML 하나를 더블클릭하면 됩니다(사진·소리 포함, 외부 요청 없음).
- 4차시에는 만화 인물이 암으로 입원하는 장면이 있습니다. 시작 전에 "마석이는 만든 인물이고, 실제 치료는 사람마다 달라요" 한마디를 권합니다.

## 이 폴더의 파일
- `index.html` — 목록 페이지(손으로 쓴 단일 HTML)
- `1/index.html` ~ `4/index.html` — **빌드 산출물. 여기서 직접 고치지 마세요.**
  원본 소스(`src/`), 근거·대본(`DATA_NOTES.md`), 검증 기록(`qa/`)은 교사 노트북의 `Lesson 3 Hooks` 폴더에 있습니다.
  거기서 고치고 `python build.py`로 다시 구운 뒤, 완성 파일을 `N/index.html`로 복사해 올립니다.
