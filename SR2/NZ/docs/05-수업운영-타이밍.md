# 노직의 철학 법정 — 수업 운영 · 타이밍 설계

외부지문 2 **3차시** (지문 3 · Nozick). 고2 영어 읽기 수업 **도입 5분**, 학생 각자 크롬북.
1차시 트롤리 → 2차시 출생 추첨(롤스) → **3차시 이 자료**.

이 문서가 정하는 것은 하나다.

> **"5분 안에 전원이 10개를 끝낸다"는 전제를 버린다.**
> 대신 **"교사가 5분에 끊어도 활동이 완결된다"** 로 설계한다.

왜 그래야 하는지는 §1의 실측 계산이 말한다. 이건 취향이 아니라 산수다.

---

## 0. 결론 먼저

요구사항 §3의 목표는 **시작 10초 + 사건당 20~25초 × 10 + 결과 20초 = 약 4분 30초~5분**이다.
요구사항 §4의 원고를 실제로 세어 고2 묵독 속도로 환산한 결과:

| 학생 층 | 묵독 속도 | 사건당 실제 | 10개 | 총계(시작·결과 포함) | 20~25초 목표 |
|---|---|---|---|---|---|
| 상위 (읽기 빠름) | 600음절/분 | **22.1초** | 3분 41초 | **4분 11초** | ✅ 들어옴 |
| 중위 | 450음절/분 | **27.8초** | 4분 38초 | **5분 08초** | ⚠️ 3초 초과 |
| 하위 (B1 하단) | 300음절/분 | **39.3초** | 6분 33초 | **7분 03초** | ❌ 1.6배 초과 |

그리고 위 수치는 **로비에서 사건 제목 10개를 읽는 시간(198음절 = 20~40초)과 재독(re-read)을 0으로 놓은 낙관치**다.
그대로 만들면 중위 학생도 **6분**, 하위 학생은 **8분**이 된다.

§1.5의 감축 조치 5개를 전부 적용하면:

| 학생 층 | 조치 후 사건당 | 조치 후 총계 |
|---|---|---|
| 상위 | 약 19초 | **3분 46초** |
| 중위 | 약 23.5초 | **4분 23초** ✅ |
| 하위 | 약 31초 | **5분 39초** ❌ |

**하위 25~30%는 어떤 감축을 해도 5분에 10개를 못 끝낸다.**
그래서 자동 종료 금지(요구사항 §3)는 배려가 아니라 **구조적 필수**이고,
**7개에서 멈춘 학생도 결과 화면(= 지문으로 가는 다리)을 볼 수 있어야** 이 활동이 성립한다. → §3

### 1.3 사건 1개의 실제 소요 분해

읽기 외의 고정 비용:

| 항목 | 시간 | 근거 |
|---|---|---|
| 판단(A냐 B냐 결정) | **3.0초** | 2지선다 + 조건 대조. 이 활동은 "고르기"가 아니라 "노직이면?"이라 한 겹 더 든다 |
| 선택 클릭 | 0.5초 | 크롬북 트랙패드 기준 |
| 반응 애니메이션 | 0.9초 | 요구사항 §3의 0.6~1.2초 중앙값 |
| '다음 사건' 클릭 | 0.5초 | |
| **소계** | **4.9초** | |

정답/오답이 반반 섞인다고 보고(피드백 평균 57.1음절) 합산:

```
중위 학생 1사건 = 115.0/7.5 (본문 15.3초) + 4.9 (고정) + 57.1/7.5 (피드백 7.6초) = 27.8초
```

10개 = 278초. + 시작 10초 + 결과 20초 = **308초 = 5분 08초.**

### 1.4 판정 — **요구사항의 20~25초는 원고를 그대로 쓰면 성립하지 않는다**

세 가지를 동시에 지킬 수 없다.

1. 사건당 20~25초 (§3)
2. 상황 2~3문장 + 훅 대사 + 선택지 2개 (§3)
3. "중요한 사실을 뺄 정도로 축약하지 마라" (§3)

**중위 학생 기준 3초, 하위 학생 기준 14초가 초과된다.**
그리고 위 계산에는 아직 **두 개의 숨은 비용**이 빠져 있다.

**숨은 비용 ① — 로비 스캔 198음절.**
요구사항 §3은 "시작 약 10초"라 했는데, 같은 §3이 "제목만 봐도 궁금해야 한다"고 요구한다.
궁금하게 만든 제목 10개는 **읽힌다.** 198음절은 상위 20초 / 중위 26초 / 하위 40초다.
**시작 10초 예산의 2~4배가 첫 화면에서 증발한다.**

**숨은 비용 ② — 재독.**
판정 조건(정당하게 / 자발적으로 / 속여 / 훔친 / 강제로)이 본문에 평문으로 섞여 있으면,
학생은 선택지를 읽은 뒤 **상황으로 눈을 되돌린다.** 상황 55음절의 약 25~30%를 다시 읽는다고 보면
사건당 +1.8~2.2초(중위), 10개 +20초.

두 비용을 넣으면 **중위 학생 실제 총계는 6분 00초, 하위는 8분 10초.**

**(1) 로비 198음절을 읽게 두지 않는다 — 가장 큰 단일 절감**

- 화면: 로비 상단에 딱 한 줄. **"아무거나 눌러도 됩니다. 순서는 상관없습니다."**
- 화면: 10개 파일 중 **미완료 1개만 살짝 크고 밝게**(시선 착지점). 나머지 9개는 동일 톤.
- 교사 대본: *"제목 다 읽지 마세요. 눈에 띄는 거 아무거나 바로 누르세요."* (§4)
- **로비는 실질적으로 1회만 방문한다.** '다음 사건' 버튼이 미답 사건으로 직행하므로(요구사항 §3),
  2~10번 사건에서는 로비 비용이 0이다. 첫 1회를 3~5초로 압축하면 20~35초가 회수된다.

**(2) 사건 화면의 제목을 다시 읽게 하지 않는다**

- 제목 19.8음절 = 상위 2초 / 중위 2.6초 / 하위 4초. **10개면 26~40초.** 로비에서 이미 읽은 글자다.
- 제목은 **본문 활자 크기의 60% 이하, 색 대비 낮게, 파일 탭처럼** 상단에 붙인다.
  본문 블록과 시각적으로 완전히 분리되면 눈이 건너뛴다.
- 훅 대사도 같은 원리. 말풍선으로 **본문 밖에** 두면 "읽는 문장"이 아니라 "보는 그림"이 된다(16음절, 2초).

**(3) 상황에서 제목·훅에 이미 있는 숫자와 비교를 뺀다 — 조건은 절대 안 뺀다**

원칙: **판정을 좌우하는 단어는 하나도 못 뺀다. 뺄 수 있는 건 중복된 숫자와 비교뿐이다.**

| 사건 | 지금 | 중복 지점 | 조치 | 절감 |
|---|---|---|---|---|
| **03** (64음절) | "…그는 3억을 벌었지만 **다른 사람은 한 달 내내 일해서 250만 원을 벌었다**" | 훅이 이미 *"내 한 달 월급의 120배"* 라고 말함 | 뒷문장을 "그는 10초 춤으로 3억을 벌었다"로 | **−18** |
| **05** (63음절) | "…기부는 거절하고 **30억짜리 슈퍼카를 샀다**" | 제목 *"기부 0원, 슈퍼카 30억"* + 훅 *"기부는 싫고, 슈퍼카는 좋아!"* — 3중 중복 | 상황에서 슈퍼카 절 삭제 | **−12** |
| **09** (63음절) | "…**원가가 3천 원임을 알고**…" | 제목 *"원가 3천 원 티셔츠, 판매가 100만 원"* | 숫자만 빼고 **"원가를 알고"** 유지 (조건 보존) | **−6** |
| **06** (60음절) | "**월급 250만 원인** 성인 팬이 …**300만 원**을" | 제목에 두 숫자 다 있음 | 상황은 "성인 팬이 정당하게 모은 돈을" | **−9** |
| **10** (60음절) | "한 성인 친구는 정당하게 번 돈 **1억**이 있고" | 제목 *"한 명은 1억, 한 명은 0원"* | 숫자 1회만 | **−6** |

**절대 못 빼는 단어 목록** (빼면 사건이 다른 사건이 된다):
`정당하게` `자발적으로` `속여` `훔친` `강제로` `모두 동의` `몰랐다` `알고` `확인한 뒤` `본인만 반대`

**(4) 선택지를 2층으로 — 두 번째로 큰 절감**

지금 선택지는 평균 A 21.6 + B 22.2 = **43.8음절**인데, 두 선택지의 **뒷부분이 서로 중복**이다.
("…이므로 **정당하다**" / "…이므로 **부당하다**")
학생은 43.8음절을 다 읽고 나서야 둘이 어디서 갈리는지 안다.

→ **판정어(2~6음절)를 크게, 근거 한 줄을 그 아래 작게.**

```
┌──────────────────────┐   ┌──────────────────────┐
│  권리 없다        A  │   │  권리 있다        B  │
│  노력하지 않았으니까 │   │  자발적으로 받았으니까│
└──────────────────────┘   └──────────────────────┘
```

- 학생은 굵은 판정어 2개(약 8음절)만 읽고 갈림을 파악한다. 근거는 필요할 때만 본다.
- 실질 읽기 43.8 → **약 20음절.** 중위 −3.3초/사건, **10개 −33초.**
- 요구사항 §4의 허용 범위 안이다("화면 분량에 맞게 다듬되"). 채점은 선택지 **ID 기준**이므로 문구 변경과 무관하다.
- 사건별 판정어는 상황에 맞춰 다르게: 01 `권리 없다 / 권리 있다`, 04 `개입 금지 / 개입 정당`,
  08 `권리 없다 / 정당하다`, 09 `무조건 부당 / 부당하지 않다`. **"정답/오답" 어감이 나는 단어는 쓰지 않는다.**

**(5) 애니메이션과 피드백을 동시에 띄운다**

- 반응 애니메이션(0.6~1.2초)이 **끝난 뒤** 텍스트가 나오면 그 시간은 순손실이다.
- 애니메이션 시작과 **동시에** 피드백 텍스트를 렌더한다. 학생은 노직이 도장을 찍는 동안 이유를 읽는다.
- 단 **'다음 사건' 버튼은 0.6초 뒤에 활성화**한다. 연타로 피드백을 건너뛰는 것을 막는다(요구사항 §3).
  0.6초는 애니메이션 안에 이미 들어 있으므로 추가 비용이 아니다.

| 순진한 설계 (다음 → 로비 → 사건) | **3클릭** | 32클릭 | 로비 왕복 10회 = §1.5(1) 절감이 전부 날아감 |

| 키보드 | **2타** | 23타 | 트랙패드 이동 0 |
| 이론적 하한 | 2 | — | 피드백 자동 소멸이 금지(§3)라 1로 못 내린다 |

**사건당 2입력이 바닥이다.** 선택 1 + 다음 1. 여기서 더 줄이려면 요구사항을 어겨야 한다.

### 2.2 클릭이 새는 곳 — 전부 막는다

| 새는 지점 | 손실 | 차단 |
|---|---|---|
| '다음 사건'이 로비로 감 | +10클릭 +로비 스캔 10회 | 미답 사건으로 **직행**. 로비 복귀는 별도의 작은 버튼 |
| 첫 실행인데 '이어하기/새로 시작' 물음 | +1클릭 + 혼란 | 저장 기록이 **있을 때만** 표시 |
| 음소거 토글을 켜러 감 | +1클릭 | 소리 **기본 OFF**(요구사항 §5). 대부분 0클릭 |
| 모션 감소를 켜러 감 | +1클릭 | `prefers-reduced-motion` **자동 감지** |
| 전체화면 안내 | +1클릭 + 크롬북 혼란 | **넣지 않는다.** 이 자료는 개인 화면용이다 |
| 마우스 이동 거리 | 사건당 0.3~0.5초 | **'다음' 버튼을 선택지가 있던 자리 바로 아래에** 렌더. 화면 하단 고정 금지 |
| 오클릭 후 되돌리기 | +2~4초 | 선택 즉시 입력 잠금(§3). **되돌리기는 제공하지 않는다** — 최초 선택이 점수다 |

### 2.3 키보드 경로 (크롬북 트랙패드보다 빠름)

키맵은 **`02-화면흐름-상태기계.md` §11이 확정한 것을 그대로 따른다.** 이 문서는 거기에 두 줄만 덧붙인다.

| 화면 | 키 (02 §11 확정) |
|---|---|
| 시작 | `Enter` / `Space` |
| 로비 | `↑↓←→` 이동 + `Enter`/`Space`, 숫자키로 직접 열기 |
| 사건 · 선택 | `A`/`1`/`←` = 첫째, `B`/`2`/`→` = 둘째 |
| 사건 · 피드백 | `Enter` = 다음 사건 |
| 어디서나 | `Esc` = 사건 목록 |

**이 문서가 추가로 요구하는 것**

1. **`Space`도 피드백 위상에서만 '다음'으로 동작하게 한다.** 크롬북에서 `Enter`보다 손이 이미 가 있다.
   대신 **`ask` 위상에서 `Space`는 아무 동작도 하지 않는다** — 연타 학생이 첫 선택지를 무작위로 찍는 걸 막는다.
   (02의 전이표 T7은 `phase==='ask'`에서 선택지 활성화만 받으므로 모순되지 않는다.)
2. 선택지 버튼 **안에** 작게 `A` / `B` 를 박아 둔다(각 1음절, 읽기 비용 사실상 0).
   하단에 한 줄 `Enter = 다음`(6음절). 키 힌트가 없으면 아무도 키보드를 안 쓴다.

## 3. 5분이 지나도 자동 종료하지 않는다

요구사항 §3: *"5분이 지나도 미완료 학생을 자동 종료하지 마라. 시간은 경과 시간 또는 목표 시간으로 보여준다."*

### 3.1 시간 표시 규칙

| 규칙 | 이유 |
|---|---|
| **카운트다운 금지.** 경과 시간 `mm:ss`만 | 남은 시간이 보이면 하위 학생이 대충 찍는다. 그러면 이 활동이 무의미해진다 |
| 시간은 **로비와 결과 화면에만.** 사건 화면에는 없다 | 읽는 중에 시계가 보이면 조급 → 오독 → 재독 → **더 느려진다** |
| 색은 회색. 빨강·깜빡임·진동 **금지** | |
| "목표 5분" 문구는 로비에 **작게 한 번**만 | 있어야 요구사항 충족. 크면 압박이 된다 |
| 진행도는 `●●●●○○○○○○` 10칸 + **"완료 4/10"** | 항상 보임 |
| **정답 수는 진행 중에 절대 표시하지 않는다** | §8 리스크 4 |

> 요구사항 §3의 *"'완료 7/10'과 '첫 선택 정답 4개'는 다른 상태로 관리한다"* 는
> 두 상태를 **내부적으로** 분리하라는 요구이지 둘 다 상시 노출하라는 요구가 아니다.
> **완료 수는 항상, 정답 수는 결과 화면에서만.** 이게 경쟁을 가장 싸게 막는다.

### 3.2 교사가 끊는 방법 — 시계가 아니라 교실을 본다

```
게임 시작
  │
  ├─ 3분 30초쯤   앞줄에서 고개가 들리기 시작 (결과 화면 도달 = 상위층)
  │
  ├─ 절반이 고개를 들면 (대략 4분 30초~5분)
  │     교사: "30초 뒤에 멈춥니다. 지금 푸는 사건까지만."
  │
  └─ 30초 뒤
        교사: "다 못 푼 사람, 그대로 두세요. 화면 아래 [지금까지 결과] 누르세요."
        → 전원이 결과 화면 = 지문으로 가는 다리에 선다
```

**핵심 장치: [지금까지 결과] 버튼.**
7개에서 멈춘 학생도 두 질문과 지문 용어를 봐야 한다. 못 보면 이 학생에게 이 5분은 그냥 날아간다.

| 항목 | 설계 |
|---|---|
| 위치 | **로비 하단에만.** 사건 화면(선택·피드백)에는 없다 |
| 조건 | **3개 이상 완료했을 때만** 나타난다 |
| 표시 | "지금까지 결과 보기 (7/10)" — 남은 개수를 숨기지 않는다 |
| 결과 화면 | `X/7`로 표시하고 **"아직 3개 남았습니다"** 한 줄. 미완료를 실패로 쓰지 않는다 |
| 복귀 | 결과 화면에서 **[남은 사건 계속]** 으로 돌아갈 수 있다 |

> **이것은 "건너뛰기 모드"가 아니다.** 요구사항 §1이 금지한 것은 *"3~4개만 선택하는 모드"* 와
> *"사건 건너뛰기"* 를 **기본 흐름에 넣는 것**이다. 기본 흐름은 그대로 `선택 → 피드백 → 다음 사건` ×10이고,
> 이 버튼은 로비 하단에, 3개 완료 후에만, 한 번 더 들어가야 보인다. → §10 충돌 ③

**⚠️ `02-화면흐름-상태기계.md`의 전이표에 이 경로가 없다.**
02의 RESULT 진입은 **T11(`allDone()` 가드) 하나뿐**이다. 그대로 구현하면 7/10 학생은 결과 화면을
영원히 못 본다. 02에 다음 한 줄을 **추가해야** 한다.

| # | 현재 | E: 이벤트 | G: 가드 | A: 동작 | 다음 |
|---|---|---|---|---|---|
| **T19** | LOBBY | `#nz-btn-result-early` | `doneCount() >= 3` | `setScreen('result')` | RESULT |

- 복귀 경로는 이미 있다 — 02의 **T14**(`#nz-btn-result-lobby` → LOBBY)를 그대로 쓴다.
- RESULT 화면은 `allDone()` 여부로 문구만 갈린다: `10개 사건 수사 완료!` vs `지금까지 7개`.
  **두 질문·지문 용어·고정 연결 문구는 두 경우 모두 똑같이 나온다.** 그게 이 버튼의 존재 이유다.
- 버튼은 **LOBBY에만** 둔다. CASE 화면(`ask`/`feedback`)에 두면 기본 흐름에 끼어들어 요구사항 §1 위반이 된다.

### 3.3 하위 학생 — 안 끝나도 괜찮다는 걸 화면이 먼저 말한다

- 시작 화면 안내 아래 한 줄: **"다 못 풀어도 괜찮습니다."**
  이 한 줄이 "몇 개까지 해야 돼요?" 질문 3~4개를 미리 없앤다.
- 로비에 남은 개수를 **빨간색으로 표시하지 않는다.** 미완료는 그냥 어두운 파일이다.
- 교사는 **누가 몇 개 했는지 묻지 않는다.** 순회하며 화면을 들여다보지도 않는다(속도가 더 떨어진다).
- 수업 끝나고 "집에서 마저 풀고 싶은 사람은" — 링크를 안내해도 되지만 **과제로 내지 않는다.**

### 3.4 먼저 끝낸 학생이 할 일 — 화면이 스스로 지시한다

빠른 학생은 3분 46초에 끝난다. **남는 1분 15초를 설계로 흡수하지 않으면 교실이 소란해진다.**
결과 화면 하단에 순서대로 셋을 둔다.

| # | 지시 | 흡수 시간 | 효과 |
|---|---|---|---|
| **1** | **"지문 3문단에서 `justice in initial holdings` 와 `justice in transfer` 를 찾아 밑줄 치세요."** | 40~60초 | **지문을 미리 펴게 만든다.** 도입이 본시로 그대로 흘러간다. 이게 최선의 흡수다 |
| **2** | "내가 틀린 사건만 다시 보기" (점수 불변) | 30~60초 | 오답 피드백 재독 = 이 활동의 학습 핵심 |
| **3** | (선택) 동의/비동의 한 번 | 5초 | §6 |

**하지 말 것**
- 빠른 학생에게 **"처음부터 다시"** 를 권하지 않는다. 점수를 리셋하고 싶은 유혹을 만든다(요구사항 §3: 최초 선택으로만 채점).
- **옆 사람 도와주게 하지 않는다.** 정답이 퍼지면 그 뒤 학생들의 판단이 오염된다.
- 남은 시간에 **지문 본문을 읽으라고 하지 않는다.** 밑줄 두 개까지만. 본시 활동을 앞당기면 본시가 빈다.

## 4. 교사 진행 대본

### 4.1 게임 전 — 30초, 그대로 읽으면 됨

각 줄 약 7초. **철학 설명을 하지 않는다**(요구사항 §3: *"처음부터 철학 원칙을 장황하게 가르치지 마라"*).

> **①** 오늘 지문 주인공 이름은 **노직**입니다. 지금은 아무것도 안 알려줄 거예요.
>
> **②** 화면에 사건 10개가 뜹니다. **여러분 생각을 묻는 게 아닙니다.**
> **노직이라면 뭐라고 할까** — 그걸 맞히는 겁니다.
>
> **③** 틀려도 됩니다. 틀리면 노직이 나와서 한마디 하는데, **그 한마디가 오늘 지문 힌트예요.**
> 제목 다 읽지 말고, 눈에 띄는 거 아무거나 바로 누르세요.
>
> **④** 다 못 풀어도 됩니다. 소리는 꺼져 있습니다. **그대로 두세요.** 시작.

체크: ⑤ **"몇 개 맞혔는지 안 물어볼 거예요."** — 넣을지는 반 분위기로 판단. 넣으면 경쟁이 확실히 줄고, 5초 든다.

### 4.2 게임 중 — 개입하지 말아야 할 지점

| 언제 | 하지 말 것 | 대신 |
|---|---|---|
| **처음 60초** (사건 01~02) | **아무 말도 하지 않는다.** | 침묵. BL 2차시의 "15초 그냥 둔다"와 같은 원리 |
| "이거 답이 뭐예요?" | 답하지 않는다 | *"화면이 알려줄 거야. 눌러봐."* |
| **오답 대사에 웃음이 터질 때** | **"조용히 해"라고 하지 않는다** | 그냥 둔다. 그 웃음이 오답 대사를 기억에 박는다 |
| **05(강제 재분배) · 08(다수결)** 에서 학생이 흥분할 때 | **정치 얘기로 받지 않는다** | *"그건 지문 읽고 다시 하자."* 도입 5분은 회수가 안 된다 |
| "선생님은 어느 쪽이에요?" | **동의/비동의를 표명하지 않는다** | *"나중에. 지금은 노직이 뭐라 할지만."* |
| 순회 | 학생 화면을 들여다보지 않는다 | 뒤에 서 있으면 읽는 속도가 떨어진다 |
| 누구든 | **점수를 소리 내어 부르지 않는다** | 한 번이라도 부르면 그 순간 경쟁 게임이 된다 |

> **2차시(롤스)와 대칭을 지킨다.** 2차시 진행안이 *"'그러니 도와야 한다'로 끝내지 않는다 — 다음 차시 노직이 정확히 그걸 반박한다"* 라고 했다.
> 3차시에서는 그 반대다. **"그러니 세금은 다 부당하다"로 흘러가지 않게 한다.**
> 지문의 노직은 **재분배 과세**를 반대하는 것이지 모든 국가 활동을 반대하지 않는다(요구사항 §2-4·5).
> 사건 04가 이 안전장치다 — 최소 국가는 **사기로부터 사람들을 보호한다.** 학생이 튀면 04를 가리킨다.

### 4.3 게임 후 — 지문으로 넘어가는 연결 발문

30초. 순서를 지킨다.

> **①** (경쟁 차단) **"몇 개 맞혔는지는 안 물어볼게요."**
>
> **②** (화면으로 시선) "화면에 영어 질문 **두 개** 보이죠. 소리 내서 읽어봅시다."
> → 학생들이 함께 읽는다: ***"Was it rightfully theirs?"*** / ***"Was the transfer voluntary?"***
>
> **③** (한국어로 한 번) "**애초에 정당한 자기 것이었나. 자발적으로 주고받았나.**
> 10개 사건이 전부 이 두 개에서 갈렸습니다."
>
> **④** (지문으로) "그 아래 영어 두 덩어리 —
> ***justice in initial holdings*** / ***justice in transfer***.
> **지문 셋째 문단에 이 두 단어가 그대로 있습니다. 펴서 찾으세요. 찾으면 밑줄.**"
>
> **⑤** (고정 문구 — 토씨 그대로)
> ### **"노직의 답에 동의하지 않아도 괜찮습니다. 이제 지문에서 그의 판단 기준을 찾아봅시다."**

- ⑤는 요구사항 §3에 **고정된 문구**다. 바꾸지 않는다. **결과 화면에도 같은 문장이 떠 있어야** 교사 말과 화면이 겹쳐 박힌다.
- ⑤ 다음에 **아무 말도 덧붙이지 않는다.** 여기서 끝이다.

## 5. 결과 화면 = 지문으로 가는 다리

결과 화면은 "점수 발표 화면"이 아니다. **지문 3문단을 찾는 지도**다. 체류 20초를 그 설계에 전부 쓴다.

### 5.1 배치 (위 → 아래)

```
├──────────────────────┬──────────────────────────────┤
│ Was it rightfully    │ Was the transfer             │  ← 가장 크게 (영어)

│ 애초에 정당한        │ 자발적으로                   │  ← 한국어 한 줄, 작게
│ 자기 것이었나?       │ 주고받았나?                  │
│                      │                              │
│ ┌──────────────────┐ │ ┌──────────────────────────┐ │
│ │ justice in       │ │ │ justice in transfer      │ │  ← 지문 용어 배지
│ │ initial holdings │ │ │                          │ │     영어 그대로만
│ └──────────────────┘ │ └──────────────────────────┘ │
│ "rightfully yours    │ "gifts voluntarily given     │  ← 지문 원문 조각
│  in the first place" │  to you by others"           │     (§5.3 때문에 필수)
│                      │                              │
│ 여기서 갈린 사건     │ 여기서 갈린 사건             │
│  ② ⑦                │  ① ③ ④ ⑤ ⑥ ⑧ ⑨ ⑩          │  ← 맞힘 ● / 틀림 ○
└──────────────────────┴──────────────────────────────┘
│  📖 지문 셋째 문단 — "two requirements" 다음 줄에 있습니다  │  ← 찾을 위치
├─────────────────────────────────────────────────────┤
│  "노직의 답에 동의하지 않아도 괜찮습니다.                │  ← 고정 문구
│   이제 지문에서 그의 판단 기준을 찾아봅시다."            │     가장 마지막·가장 굵게
├─────────────────────────────────────────────────────┤
│  (선택) 나는 노직에게 대체로 …  [동의] [동의 안 함]     │  ← §6, 아주 작게
└─────────────────────────────────────────────────────┘
```

**배치 규칙 5개**

1. **영어 질문이 화면에서 가장 크다.** 한국어 번역은 그 아래 작게 한 줄. 반대로 하면 학생 눈이 한국어에 붙고,
   지문에서 스캔할 문자열이 머리에 안 남는다. 이건 영어 읽기 수업이다.
2. **`justice in initial holdings` / `justice in transfer` 는 영어 그대로만 쓴다.**
   "최초 취득의 정의" 같은 한국어 번역을 크게 붙이면 **학생이 지문에서 그 글자를 못 찾는다.**
   이 두 덩어리는 **번역이 아니라 검색어**다.
3. **찾을 위치를 준다.** "지문 셋째 문단, `two requirements` 다음."
   이게 없으면 20초 안에 못 찾고, 못 찾으면 다리가 끊긴다.
4. **사건 번호 칩으로 두 질문을 되짚는다.** 학생은 방금 푼 10개가 이 두 질문으로 정리되는 걸 본다.
   맞힘 `●` / 틀림 `○` 만. **퍼센트도, 진단 문구도 없다.**
5. **고정 문구가 화면 최하단, 가장 굵게.** 설문(§6)은 그 아래로 내려 시각적 무게를 최소화한다.

### 5.2 10개 사건 → 두 질문 대응 (칩의 근거)

| 질문 | 사건 | 이 사건에서 갈린 지점 |
|---|---|---|
| **Q1 Was it rightfully theirs?**<br>*justice in initial holdings* | **02** 훔친 돈 장학금<br>**07** 훔친 돈 상속 | 출처가 부정하면 그다음이 아무리 깨끗해도 소용없다 |
| **Q2 Was the transfer voluntary?**<br>*justice in transfer* | **01** 자발적 상속<br>**03** 자발적 후원<br>**06** 자발적 선물<br>**09** 정직한 고가 거래<br>**10** 자발적 반반 | 자발성이 **있어서** 정당 |
| | **04** 사기<br>**05** 강제 징수<br>**08** 다수결 강탈 | 자발성이 **없어서** 부당 |

- **01 vs 07** 이 Q1/Q2를 가르는 쌍이다(요구사항 §8 검증 항목). 결과 화면에서 두 칩이 서로 다른 열에 서는 것 자체가 설명이다.
- **04 vs 09**(속임수 있는 거래 / 비싸지만 정직한 거래), **05 vs 10**(강제 / 자발적)도 같은 열 안에서 ±로 갈린다.
- 04는 **최소 국가가 사기로부터 보호한다**는 별개 논점이기도 하다. 화면에서 여기까지 설명하지 않는다 —
  **교사가 §4.2의 안전장치로만 쓴다.** 20초 화면에 세 번째 기둥을 세우면 두 질문이 흐려진다.

### 5.3 ⚠️ 두 질문은 지문에 그대로 있지 않다 — 반드시 처리할 것

요구사항 §3이 고정한 두 문장을 지문(§01-지문3-원문.md)에서 검색하면 **둘 다 안 나온다.**

| 화면 (요구사항 고정) | 지문 실제 표현 |
|---|---|
| "Was it rightfully theirs?" | "…if the resources you used to make your money were **rightfully yours in the first place**" |
| "Was the transfer voluntary?" | "…through **free exchanges** in the marketplace or from **gifts voluntarily given** to you by others" |

학생이 화면 문장을 그대로 `Ctrl+F` 하듯 스캔하면 **못 찾고 포기한다.** 다리가 거기서 끊긴다.

**조치:** 각 질문 카드에 **지문 원문 조각을 작은 글씨로 병기한다.**
- Q1 아래: `"rightfully yours in the first place"`
- Q2 아래: `"gifts voluntarily given to you by others"`

화면의 두 질문은 **기억용 요약**이고, 그 아래 조각이 **지문에서 찾을 실제 문자열**이다.
`justice in initial holdings` / `justice in transfer` 두 덩어리는 지문에 **글자 그대로** 있으므로 이게 1차 앵커다.

## 6. 마지막 동의/비동의 설문 (선택 기능)

요구사항 §3: *"선택 기능으로 마지막에만 … 채점하지 말고 필수 응답으로 만들지 마라. 문항마다 동의도 설문을 추가하지 마라."*

### 6.1 화면 규칙

| 규칙 | 구현 |
|---|---|
| **결과 화면에만, 1회만** | 사건 10개 화면 어디에도 없다 |
| **필수 아님** | 안 눌러도 아무 일도 안 생긴다. "건너뛰기" 버튼조차 두지 않는다 — 그게 있으면 필수처럼 보인다 |
| **채점 금지** | 정확도 `X/10`과 **같은 블록에 두지 않는다.** 고정 문구 아래로 분리 |
| **응답 후 반응 한 줄** | "기록했습니다. 채점하지 않습니다." — 그게 전부 |
| **라벨 금지** | "당신은 자유지상주의자" / "노직형 인간" 같은 결과 라벨 **절대 금지** |
| **롤스 금지** | 요구사항 §3 명시. 낮은 점수에 "롤스가 좋아합니다" 류 금지 |
| 저장 | 자기 기기 localStorage에만. 전송 없음, 집계 없음(서버가 없다) |
| 문구 | "(선택) 나는 노직의 판단에 대체로 …" `[동의한다]` `[동의하지 않는다]` |

### 6.2 교사가 이걸 쓰는 법 — **집계하지 않는다**

서버가 없어서 집계가 불가능한 게 아니라, **집계하면 안 되기 때문에** 안 한다.
고2 교실에서 재분배에 대한 찬반을 손 들어 세는 건 **정치적 입장 표명을 강요하는 것**이다.

쓰는 방법은 하나다. **지문을 다 읽은 뒤의 재질문.**

> **(본시 후반, 지문 다 읽고)**
> "아까 게임 끝에 동의 / 동의 안 함 눌렀던 사람 있죠. 손 안 들어도 돼요. 혼자 생각만 해요.
> **지문 읽고 나서 그때랑 생각이 바뀐 사람?**
> 바뀌었으면 — **뭐가 바뀌게 만들었는지** 그게 오늘 배운 겁니다."

- 개인 기기에 남아 있으므로 학생은 자기 답을 다시 열어 볼 수 있다(재접속해도 유지).
- **사전/사후 비교가 개인 안에서만 일어난다.** 집계도, 노출도, 강요도 없다.
- 차시가 끝난 뒤 쓸 수도 있다: 서술형 한 줄 — *"게임에서 당신이 노직과 가장 다르게 판단한 사건 하나를 고르고, 왜 다른지 쓰시오."*
  이건 **동의 여부가 아니라 근거**를 평가한다.

### 6.3 하지 말 것

- 동의 비율을 **거수로 세기**
- 동의/비동의를 **수행평가·생기부에 연결하기**
- "동의 안 함"을 고른 학생에게 **되묻기** ("왜 동의 안 해?")
- 문항마다 동의도 묻기 (요구사항 §3 명시 금지 — **읽기 시간이 10배가 되고 활동 성격이 설문으로 바뀐다**)

| 05·08에서 정치 논쟁이 터짐 | 교사가 **"지문 읽고 다시"** 로 닫는다 (§4.2). 사건 04가 "최소 국가도 일한다"는 반례로 준비돼 있다 |
| "노직이 정답이에요?" | 화면 내레이션이 노직을 절대 정답으로 선언하지 않는다(요구사항 §5). 정답 = **"노직의 판단과 일치"** 로 표기. 고정 연결 문구가 이걸 마무리한다 |
| 웃음이 커져서 통제 불능 | 오답 대사는 **판단 근거를 반박**하지 학생을 모욕하지 않는다(요구사항 §3). 지휘봉은 사람을 때리지 않는다 |
| 학생이 답을 연타로 찍음 | 선택 즉시 입력 잠금 + '다음' 0.6초 지연 + 선택 화면에서 `Space` 무효 (§2.2·§2.3) |

## 10. 요구사항과 충돌하는 지점 (구현 전에 알고 갈 것)

| # | 충돌 | 이 문서의 처리 |
|---|---|---|
| ① | **"사건당 20~25초"** vs **"상황 2~3문장 + 훅 + 선택지 2개"** vs **"중요한 사실을 뺄 정도로 축약하지 마라"** | 셋 다는 하위층에서 불가능. **조건 단어는 하나도 안 빼고**, 중복 숫자·선택지 중복 구조·제목 재독만 깎는다(§1.5). 그래도 하위층은 사건당 31초 |
| ② | **"시작 약 10초"** vs **"제목만 봐도 궁금해야 한다"**(제목 10개 = 198음절) | 로비는 **읽는 화면이 아니라 고르는 화면**으로. 교사 멘트 + 화면 한 줄로 스캔을 3~5초로 압축 (§1.5-1) |
| ③ | **"10개 전부 풀어야 완료"·"건너뛰기 모드 금지"** vs **"자동 종료 금지"** — 미완료 학생의 결과 화면 접근 경로가 요구사항에 **없다** | **[지금까지 결과 보기]** 를 기본 흐름 밖(로비 하단·3개 이상 완료 시)에 둔다. 기본 흐름은 그대로 10개 (§3.2). **교사 확인 필요 지점** |
| ④ | 결과 화면의 두 질문이 **지문에 그대로 없다** (요구사항 고정 문구 vs 지문 실제 표현) | 지문 원문 조각을 작게 **병기**. `justice in initial holdings`/`justice in transfer`가 1차 앵커 (§5.3) |
| ⑤ | **"정확도 X/10 표시"**(§3) vs **"경쟁·성향 해석 금지"**(§3·§5) | 점수는 **결과 화면에서 한 줄만.** 진행 중 비노출, 등급·랭킹·축하 이펙트 없음, 교사가 호명하지 않음 (§8) |
| ⑥ | 사건 04·05·08은 **두 질문만으로 안 덮인다** (최소 국가의 사기 방지 / 강제 금지 논점) | 결과 화면에는 세 번째 기둥을 세우지 않는다(20초에 못 넣는다). **교사 대본의 안전장치로만** 쓴다 (§4.2·§5.2) |
| ⑦ | localStorage 새로고침 복구가 **게스트 모드에서 보장 안 됨** | 저장 실패해도 작동(요구사항 §6). **교사가 "저장됩니다"라고 약속하지 않는다** (§7.2) |

### 10.1 `02-화면흐름-상태기계.md` 와의 대조 (같은 시각에 병행 작성됨)

| 항목 | 02의 값 | 이 문서의 실측 | 처리 |
|---|---|---|---|
| 사건 1개 읽기 | 12~15초 | **상위 11.5 / 중위 15.3 / 하위 23.0초** | 02의 값은 **상위~중위 밴드**다. 하위 밴드가 02에 없다 |

| 합계 | 약 4분 30초~5분 | 감축 전 **4분 11초 / 5분 08초 / 7분 03초** | 02의 값은 상위층 기준. 반 전체 기준이 아니다 |
