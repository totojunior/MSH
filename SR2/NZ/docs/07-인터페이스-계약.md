# 07 · 인터페이스 계약 — 구현자 단일 계약서

> **이 문서 하나 + 자기 담당 설계 문서 하나**로 여섯 명이 조율 없이 병렬로 코드를 쓴다.
> 여기 없는 이름·문구·속성은 **구현되지 않는다.** 필요하면 이 문서를 먼저 고친다.

## 1. 모듈 소유권

빌드(=전역 정의) 순서는 `assemble.js` 의 `JS_ORDER` 가 강제한다.
**뒤 파일이 앞 파일의 전역을 읽는다. 앞 파일은 뒤 파일을 참조하지 않는다**(런타임 호출은 예외).

```
cases.js → copy.js → state.js → audio.js → court3d.js → ui.js → boot.js
CSS: base.css → ui.css        HTML: ui.html
```

| 담당 | 파일 | 노출 전역 | 책임 | **절대 건드리지 않는 것** |
|---|---|---|---|---|
| **A. 문구·상태** | `src/copy.js` | `NZ.COPY` | 화면에 나오는 모든 문자열·문구 템플릿·정답 반응 대사 풀·사건별 보충 문구 | DOM, `document`, 타이머, `NZ.CASES` 수정, 상태 |
| | `src/state.js` | `NZ.State`, `NZ.CONFIG` | 게임 상태 단일 소스, 채점, 저장/복구/초기화, 경과 시간 | **`document` 를 단 한 번도 참조하지 않는다.** three.js, 오디오, 문구 |
| **B. 마크업·스타일** | `src/ui.html` | — | §6 의 id·`data-*`·ARIA 골격. **문자열은 비워 두고 ui.js 가 채운다**(§6.7 예외 목록만 하드코딩) | JS, 인라인 `style`, 인라인 `on*` 핸들러 |
| | `src/base.css` | — | 리셋, `:root` 토큰(§7), 폰트 스택, 유틸(`.nz-sr` `.nz-nb` `.nz-ko` `.nz-tnum` `.nz-icon`) | 컴포넌트 스타일 |
| | `src/ui.css` | — | 레이아웃 골격, 컴포넌트, `data-*` 상태 스타일, 미디어 쿼리, 모션 감소 블록(**항상 맨 끝**) | id 신설, `.is-*`/`.has-*` 클래스, `!important`(허용 3곳 외), `text-overflow`, `-webkit-line-clamp` |
| **C. 렌더·전이·입력** | `src/ui.js` | `NZ.UI` | DOM 렌더링, 화면 전이, 키보드·클릭 입력, 입력 잠금, 포커스 이동, `aria-live`, `NZ.Court`/`NZ.Audio`/`NZ.State` **호출** | `#nz-gl`·`#nz-fb-bust` 내부(§6.1), `THREE` 직접 참조, `Court.ok`/`Court.mode` 로 분기, 애니메이션 길이 상수 복제, 화면 문자열 리터럴 |
| **D. 3D + 폴백** | `src/court3d.js` | `NZ.Court` | three.js r134 법정·노직 리그·키프레임·성능 사다리·2D SVG 폴백(같은 API) | `#nz-root` 이하 DOM(`data-three` 갱신은 §8.7 예외), `NZ.State` 쓰기, `NZ.UI` 호출, 캔버스 CSS 크기·`--nz-*` 변수, 3D 안에 글자 굽기 |
| **E. 효과음·시작** | `src/audio.js` | `NZ.Audio` | WebAudio 합성 효과음 4종, 기본 OFF, 사용자 제스처 안에서만 `AudioContext` 생성 | 외부 오디오 파일, 자동 재생, DOM 조회, 상태 |
| | `src/boot.js` | `NZ.start` | 부팅 6줄(§11). 그 이상 아무것도 하지 않는다 | 렌더링, 상태 변형, 3D 내부 |
| **F. 테스트** | `src/test/run.js` | — | `node SR2/NZ/src/test/run.js`. 불변식·채점·sanitize·문구 길이·계약 준수 검증 | 프로덕션 파일 수정. `assemble.js` 의 `JS_ORDER` 에 포함되지 않는다 |

**A~F 는 서로의 파일을 열지 않는다.** 교차점은 이 문서에 적힌 전역 이름과 DOM id 뿐이다.

## 2. 전역 계약

```js
window.NZ = {
  CASES : /* cases.js  */ ,   // 사건 10개 (확정, 수정 금지)
  COPY  : /* copy.js   */ ,   // 모든 화면 문구            §4
  CONFIG: /* state.js  */ ,   // 상수                      §3
  State : /* state.js  */ ,   // 상태·채점·저장            §5
  Audio : /* audio.js  */ ,   // 효과음                    §9
  Court : /* court3d.js*/ ,   // 3D 또는 2D 폴백           §8
  UI    : /* ui.js     */ ,   // 렌더·전이·입력
  start : /* boot.js   */     // 부팅 함수                 §11
};
```

**이 8개가 전부다.** `NZ.DATA` · `NZ.bus` · `NZ.layout` · `NZ.motion` · `NZ.a11y` · `NZ.sfx` · `NZ.main` **금지.**
(`04-레이아웃-접근성.md` §11.3 의 `NZ.layout` / `NZ.motion` / `NZ.a11y` 는 **ui.js 내부 함수**로 내린다.
`02-화면흐름-상태기계.md` §7.6 의 `NZ.bus` 와 `03-3D연출-명세.md` §10 의 `nz:impact` CustomEvent 는 **폐기한다.**)

### 2.1 호출 방향 — 단방향

```
boot.js ──► State.init() ──► Court.init() ──► Audio.init() ──► UI.start()

            ui.js ──► NZ.State   (읽기 + 쓰기)
            ui.js ──► NZ.Court   (호출만)
            ui.js ──► NZ.Audio   (호출만)
            ui.js ──► NZ.COPY / NZ.CASES / NZ.CONFIG  (읽기)

  court3d.js ──X──► ui.js / State / Audio        (아무것도 부르지 않는다)
    audio.js ──X──► 그 무엇도                     (부르지 않는다)
    state.js ──X──► document / Court / Audio     (참조조차 하지 않는다)
```

`NZ.UI` 가 노출하는 것은 `NZ.UI.start()` 하나다. 다른 모듈은 그것조차 부르지 않는다(boot.js만 부른다).

### 2.2 각 파일의 형태 (assemble.js 가 기계 검사)

```js
(function () {
  'use strict';
  window.NZ = window.NZ || {};
  /* … */
  window.NZ.XXX = XXX;
})();
```

금지: `import`/`export`, `require()`, `fetch()`, `XMLHttpRequest`, 외부 URL(구글 폰트 제외),
문자열 안의 리터럴 `</script`, `TODO`/`FIXME`/`구현 예정`/`placeholder implementation`.
`Date.now()` · `Math.random()` 은 자유롭게 써도 된다.

## 3. `NZ.CONFIG` — 상수 (state.js 가 정의, 모두가 읽는다)

```js
NZ.CONFIG = {
  v            : 1,
  total        : 10,            // 사건 수. NZ.CASES.length 와 반드시 같다
  schema       : 1,             // 저장 스키마 버전 (nz.progress 의 v)
  KEY_PROGRESS : 'nz.progress',
  KEY_PREFS    : 'nz.prefs',
  ARM_MS       : 150,           // 사건 진입 후 선택지 무장 지연
  NEXT_ARM_MS  : 600,           // 피드백 표시 후 '다음' 무장 지연 (06 §4-3)
  STALE_MS     : 7200000,       // 2h. 이어하기 기본 포커스 판정
  CLOCK_MS     : 1000,          // HUD 시계 갱신 주기
  MAX_ELAPSED  : 86400000,      // 24h. 이보다 크면 손상으로 본다
  REACT_MIN    : 600,           // Court.react() 반환 하한 (R10)
  REACT_MAX    : 1200           // Court.react() 반환 상한 (R10)
};
```

- **ui.js 는 애니메이션 길이 상수를 두지 않는다.** 피드백 타이머는 `Court.react()` 의 반환값이다(R9).
- `ARM_MS` / `NEXT_ARM_MS` 는 애니메이션 길이가 아니라 **입력 무장 지연**이므로 여기 있는 게 맞다.

## 4. `NZ.COPY` — 화면 문구 전량

**ui.js 는 화면에 나가는 문자열 리터럴을 단 하나도 갖지 않는다.** 전부 여기서 읽는다.
요구사항에 **글자 그대로 고정된 문구**는 아래에서 **[고정]** 으로 표시한다. 한 글자도 바꾸지 않는다.

### 4.0 템플릿 치환

```js
NZ.COPY.fill('완료 {done}/{total}', { done: 3, total: 10 })   // -> '완료 3/10'
```
`fill(tpl, map)` → `string`. `{키}` 를 `map` 값으로 치환. 없는 키는 빈 문자열. **HTML 을 만들지 않는다**(텍스트 전용).

### 4.1 최상위 키와 타입

| 키 | 타입 | 내용 |
|---|---|---|
| `COPY.v` | `1` | 버전 |
| `COPY.fill` | `function(string, Object) => string` | §4.0 |
| `COPY.app` | `{title, subtitle}` | 게임 이름 |
| `COPY.start` | `object` | 시작 화면 |
| `COPY.resume` | `object` | 이어하기 분기 패널 |
| `COPY.hud` | `object` | HUD |
| `COPY.lobby` | `object` | 로비 |
| `COPY.file` | `object` | 사건 카드 상태 라벨 |
| `COPY.case` | `object` | 사건 화면 |
| `COPY.feedback` | `object` | 피드백 |
| `COPY.approve` | `string[]` | **정답 반응 대사 풀** |
| `COPY.caseNote` | `{[caseId]: string}` | 사건별 보충 한 줄 (06 §2-4) |
| `COPY.linger` | `{[caseId]: string}` | 사건별 '남는 물음' (06 §2-5) |

| `COPY.confirm` | `object` | 초기화 확인 모달 |
| `COPY.flat` | `object` | 2D 폴백 안내 |
| `COPY.a11y` | `object` | `aria-live` / `aria-label` 문구 |

### 4.3 화면 문자열 화이트리스트 (06 §2-1 [심각])

화면 어디에도 다음 문자열이 **0건**이어야 한다 — 테스트가 검사한다(§13 T-09).

> `정답` · `오답` · `맞았습니다` · `틀렸습니다` · `Correct` · `Wrong` · `APPROVED` · `롤스` · `Rawls`

- 3D 도장에는 **글자를 새기지 않는다**(03 §1.3: 3D 안에 문자 금지). 도장은 잉크 링과 모양뿐이다.
- `NZ.CASES` 의 `answerId` 같은 **코드 내부 식별자**는 검사 대상이 아니다. 화면에 나가는 문자열만이다.
- `노직의 예상 답` 은 요구사항 §3 원문 표현이므로 **유지한다**(06 §2-1 이 제안한 `노직이라면 골랐을 쪽` 은
  채택하지 않는다 — 우선순위 §0 에 따라 00 이 06 을 이긴다). 06 §2-1 의 실질 요구인
  "'정답/오답' 문자열 전량 제거"는 위 화이트리스트로 충족된다.

## 5. `NZ.State` — 상태·채점·저장

`state.js` 는 **`document` 를 단 한 번도 참조하지 않는다.** `NZ.CASES` 에서 읽는 것은
`id`, `options[].id`, `answerId` 세 가지뿐이다.

### 5.1 타입

```js
/**
 * @typedef {'ask'|'lock'|'feedback'} Phase
 * @typedef {'start'|'lobby'|'case'|'result'} Screen
 * @typedef {'unread'|'answered'|'done'} CaseState
 *
 * @typedef {Object} Snapshot              // 깊은 복사본. 호출자가 고쳐도 내부는 안 변한다
 * @property {1}       v
 * @property {number}  startedAt
 * @property {number}  savedAt
 * @property {number}  elapsedMs
 * @property {Object<string,string>} firstChoice
 * @property {string[]} done
 * @property {?string} current
 * @property {Phase}   phase
 * @property {Screen}  screen
 * @property {?('yes'|'no')} agree
 *
 * @typedef {Object} AnswerResult
 * @property {boolean} accepted    // false = 이미 답한 사건 (기록 변화 없음)
 * @property {string}  choiceId    // 최종적으로 유효한 최초 선택 ID
 * @property {boolean} match       // 노직의 예상 답과 일치하는가  ← '정답' 아님
 * @property {string}  expectedId  // 노직의 예상 답 옵션 ID
 * @property {?string} reason      // null | 'already' | 'unknown-case' | 'unknown-choice'
 */
```

**필드명에 `correct` / `정답` 을 쓰지 않는다. `match` 다.**

### 5.2 저장 스키마 (`localStorage['nz.progress']`)

```json
{
  "v": 1,
  "startedAt": 1757836800000,
  "savedAt": 1757836912345,
  "elapsedMs": 84210,
  "firstChoice": { "c01": "c01-gift", "c02": "c02-outcome", "c07": "c07-stolen" },
  "done": ["c01", "c02"],
  "current": "c07",
  "phase": "feedback",
  "screen": "case",
  "agree": null
}
```

| 필드 | 타입 | 불변성 |
|---|---|---|
| `v` | `1` | 불일치면 폐기 |
| `startedAt` | `number` ms | `reset()` 전까지 불변. `resume()` 이 건드리지 않는다 |
| `savedAt` | `number` ms | 매 저장 갱신 |
| `elapsedMs` | `number` | 누적. 탭이 닫혀 있던 시간 제외. 단조 증가 |
| `firstChoice` | `{[caseId]: optionId}` | **쓰기 1회.** 채점의 유일한 근거 |
| `done` | `caseId[]` | 추가만. 오답도 포함 |
| `current` | `caseId \| null` | 가변 |
| `phase` | `'ask'\|'lock'\|'feedback'` | `screen!=='case'` 면 무의미 |
| `screen` | `'lobby'\|'case'\|'result'` | **`'start'` 는 저장하지 않는다** |
| `agree` | `'yes'\|'no'\|null` | 채점 대상 아님. **결과 화면에 다시 렌더하지 않는다**(06 §2-6) |

**`order` 필드도, 셔플 시드도 없다(R2).** `feedbackOpen` 불리언도 없다 — `phase==='feedback'` 의 파생값이다.

`localStorage['nz.prefs']` (R6, 진행 기록과 분리 — `reset()` 이 건드리지 않는다):

```json
{ "v": 1, "muted": true, "motion": null }
```
`muted:true` = 효과음 OFF(기본값). `motion`: `null`=OS 설정 따름 / `'reduced'` / `'full'`.

### 5.4 채점 규칙

1. **최초 선택으로만 계산한다.** `firstChoice[caseId]` 는 `hasOwnProperty` 로 막힌 **쓰기 1회**.
2. **판정은 ID 비교뿐이다.** `firstChoice[id] === CASES.byId[id].answerId`.
   `answerId` 는 `cases.js` 의 내용 기반 ID(`c01-gift`, `c07-stolen` …) 그대로다.
   **어떤 코드도 ID 를 문자열 조합으로 만들지 않는다**(R1). 화면의 ①② 는 렌더 순서가 붙이는 라벨일 뿐이다.
3. `markDone()` 은 **피드백이 화면에 완전히 표시된 직후** ui.js 가 호출한다(R4).
   `score()` 는 `done` 만 센다 → `score() ≤ completedCount()` 가 **항상** 참.
4. `answer()` 는 멱등이다. 두 번째 호출은 기록을 건드리지 않고 기존 결과를 반환한다. **throw 금지.**

```js
answer('c03', 'c03-free')  // {accepted:true,  choiceId:'c03-free', match:true,  expectedId:'c03-free', reason:null}
answer('c03', 'c03-gap')   // {accepted:false, choiceId:'c03-free', match:true,  expectedId:'c03-free', reason:'already'}
```

### 5.5 경과 시간

```js
var anchor = Date.now();
function flushClock() { var n = Date.now(); st.elapsedMs += (n - anchor); anchor = n; }
function elapsedMs()  { return st.elapsedMs + (Date.now() - anchor); }
```
`save()` 맨 위에서 `flushClock()`. `Date.now() - startedAt` 으로 계산하지 않는다
(4교시에 시작해 6교시에 이어한 학생에게 `2:13:00` 이 뜬다).
표시는 **경과 시간만**. 카운트다운 금지, 5:00 을 넘겨도 경고 스타일로 바뀌지 않는다(06 §4-8).

### 5.6 저장 · 복구

| 시점 | 호출 |
|---|---|
| `answer()` 성공 / `markDone()` 변경 / `setCurrent`·`setScreen`·`setPhase`·`setAgree`·`setMuted`·`setMotion` | 즉시 |
| `visibilitychange`(hidden) · `pagehide` | 즉시 (ui.js 가 `State.save()` 호출 — state.js 는 `document` 를 모른다) |
| 매 프레임 / 타이머 | **금지** |

```js
function save() {
  flushClock(); st.savedAt = Date.now();
  try { localStorage.setItem(NZ.CONFIG.KEY_PROGRESS, JSON.stringify(st)); return true; }
  catch (e) { storageOkFlag = false; return false; }
}
```
**읽기도 전부 try/catch.** 실패해도 throw 하지 않고 메모리로 게임이 그대로 굴러간다(R6).

### 5.7 `sanitize(raw)` → `{state, repaired}`

| 상황 | 처리 |
|---|---|
| 키 없음 / `JSON.parse` 실패 / 최상위가 객체 아님 | 폐기 → fresh |
| `v !== 1` | 폐기 → fresh (v1이므로 마이그레이션 없음) |
| `firstChoice` 가 객체 아님 / `done` 이 배열 아님 | 폐기 → fresh |
| `done`·`firstChoice` 에 `CASES` 에 없는 `caseId` | **그 항목만 제거**, `repaired=true` |
| `firstChoice[id]` 가 그 사건의 `options[].id` 에 없음 | 그 항목 제거 + `done` 에서도 제거, `repaired=true` |
| `done` 중복 | 제거, `repaired=true` |
| `done` ⊄ `keys(firstChoice)` | 초과분 제거, `repaired=true` |
| `current` 가 `CASES` 에 없음 | `current=null`, `screen='lobby'` |
| `screen` 이 미지 / `'start'` | `'lobby'` |
| `screen==='result'` 인데 `!allDone()` | `'lobby'` |
| `phase==='lock'` | **`'feedback'` 으로 승격** (반응 애니메이션은 재생하지 않는다) |
| `phase` 가 미지 | `'ask'` |
| `startedAt` 이 숫자 아님 | `Date.now()` |
| `elapsedMs` 가 숫자 아님 ∨ 음수 ∨ `> MAX_ELAPSED` | `0` |
| `agree` 가 `'yes'/'no'/null` 아님 | `null` |

`repaired===true` 면 승격 직후 한 번 `save()` 해서 고쳐진 형태를 굳힌다. **콘솔 에러 0건.**

**의미 있는 진행** = `done.length>0 ∨ keys(firstChoice).length>0 ∨ screen==='result'`.
로비까지만 갔다가 새로고침한 경우는 **묻지 않고 새로 시작한다.**

### 5.8 불변식 (테스트가 고정한다 — §13)

| # | 불변식 |
|---|---|
| I1 | `done ⊆ keys(firstChoice)` |
| I2 | `0 ≤ score() ≤ completedCount() ≤ 10` |
| I3 | `firstChoice[id]` 는 `reset()` 전까지 불변 |
| I4 | `nextUnanswered(x) === null ⟺ allDone()` |
| I5 | `screen==='result' ⇒ allDone()` |
| I6 | 같은 사건을 n번 열어도 `completedCount()`·`score()` 변화 0 |
| I7 | `elapsedMs()` 단조 증가 ∧ ≥ 0 |
| I8 | 모든 `answerId` 가 그 사건의 `options[].id` 안에 존재 |

**규칙 4개**

1. `#nz-root[data-screen]` 이 화면 전환의 **유일한** 스위치다(R8). `style.display` 금지. `el.hidden` 만 쓴다.
   비활성 `.nz-screen` 에는 `hidden` 도 함께 건다.
2. **색으로만 구분하지 않는다.** `data-verdict` 는 글리프(`✓`/`≠`) + 글자(`일치`/`다름`) +
   카드 좌측 바(실선/점선)를 함께 바꾼다. `data-state` 도 배지 글자를 바꾼다.
3. `data-*` 는 상태의 **거울**이지 상태가 아니다. 진실은 `NZ.State` 에만 있다.
   `dataset` 을 읽어 분기하지 않는다 — 클릭 핸들러가 `currentTarget.dataset.caseId` / `.choiceId` 를
   **주소**로 읽는 것만 허용한다.
4. `role="main"` 은 현재 화면인 `.nz-screen` **하나에만** 붙는다. 전환 시 떼고 옮긴다.

### 6.7 `ui.html` 에 하드코딩해도 되는 문자열

아래 2개뿐이다. 나머지는 **전부 빈 채로** 두고 ui.js 가 `NZ.COPY` 에서 채운다.

`#nz-hud-clock` 의 `0:00` · `.nz-choice-key` 의 `1` `2`.

`#nz-hud-done` · `#nz-lobby-progress` · `#nz-result-score` 는 **한 요소의 `textContent` 전체**를
`COPY.fill()` 결과로 덮어쓴다. 자식 `<b>`/`<span>` 을 두지 않는다 —
두면 `textContent` 대입이 그것을 지워 버려 두 번째 렌더에서 숫자가 사라진다.


JS가 제어한다. `!important` 허용 위치는 `.nz-sr` · `[hidden]{display:none!important}` · 이 블록 **3곳뿐**이다.

초당 3회를 넘는 휘도 변화 금지. 전체 화면 플래시 금지. 오답 연출에서 화면 흔들기·카메라 전진 금지.

## 8. `NZ.Court` — 3D / 2D 폴백 (같은 API)

### 8.1 API (R9 — 고정)

```js
NZ.Court.init(canvasEl)   // -> boolean   성공 true. 실패 시 내부에서 2D 폴백으로 전환하고 false
NZ.Court.ok               // boolean      3D가 살아 있는가
NZ.Court.mode             // 'three' | 'flat'
NZ.Court.react(mood,opts) // -> number    mood: 'approve'|'rebut'. 반환 = 연출 지속 ms (600~1200)
NZ.Court.setPose(name)    // -> void      'idle'|'ready'|'review'  애니메이션 없이 즉시 포즈
NZ.Court.setScene(name)   // -> void      'start'|'lobby'|'case'|'result'  카메라/구도 프리셋
NZ.Court.resize()         // -> void
NZ.Court.pause()          // -> void      렌더 루프 정지
NZ.Court.resume()         // -> void      렌더 루프 재개
NZ.Court.dispose()        // -> void
```

**ui.js 는 3D/2D 분기 코드를 한 줄도 갖지 않는다.** `Court.ok` / `Court.mode` 로 분기 **금지**
(진단·부팅 시 `data-three` 표기 외 용도 없음). 3D 초기화가 실패하면 **완전히 같은 API 를 가진
폴백 객체가 `NZ.Court` 자리에 들어간다.**

### 8.2 `init(canvasEl)` → `boolean`

| | |
|---|---|
| 인자 | `HTMLCanvasElement`. `null`/생략이면 `document.getElementById('nz-gl')` |
| 반환 | `true`=3D 가동 / `false`=폴백. **`false` 여도 모든 메서드가 정상 동작한다** |
| 동기/비동기 | **동기.** 리턴 시점에 렌더러·씬·리그·옵저버·rAF 루프가 준비돼 있다 |
| 재호출 | 두 번째부터 아무 일도 하지 않고 현재 `ok` 반환 |
| 예외 | **절대 throw 하지 않는다.** 전체 try/catch |

부작용: `#nz-gl` 의 형제로 `<svg id="nz-fb-bust" aria-hidden="true" hidden>` 삽입(Court 소유),
`ResizeObserver(#nz-gl)` · `visibilitychange` · `webglcontextlost/restored/creationerror` ·
`matchMedia('(prefers-reduced-motion: reduce)')` 구독.
**`canvas.style` · `--nz-*` 변수 · 레이아웃 CSS 를 건드리지 않는다.**

### 8.3 `react(mood, opts)` → `number` (ms)

```js
/** @typedef {{seed?:number, streak?:number, variant?:?number, hold?:boolean}} ReactOpts */
```

| | |
|---|---|
| `mood` | `'approve'` = 노직의 판단과 일치 / `'rebut'` = 불일치. **그 외 문자열은 조용히 무시하고 `REACT_MIN` 반환.** 콘솔 경고 금지(수업 중 노이즈 금지) |
| `opts.seed` | 사건 인덱스 0~9. 변주 선택용. 기본 0 |
| `opts.streak` | 연속 일치/불일치 수. `rebut` 에서 3 이상이면 **조용한 변주로 강제**(강도 누적 금지, 06 §3-7) |
| `opts.variant` | 변주 강제 지정(테스트용). 기본 `null` |
| `opts.hold` | `true` 면 타임라인 종료 후 idle 로 자동 복귀하지 않는다 |
| 같은 mood 재호출 | 재생하지 않고 **남은 ms** 반환 |
| 재생 중 다른 mood | 0.12s 크로스페이드 후 새 타임라인 |

**반환값 표 — 전부 600~1200 안(R10)이고, 절대 `undefined` 가 아니다.**

| 조건 | 반환 |
|---|---|
| `approve` 기본 | `850` |
| `approve` 모션 감소 | `700` |
| `rebut` v0 / v1 / v2 / v3 | `1050` / `1100` / `1150` / `950` |
| `rebut` 모션 감소 | 위 값 **그대로** (모션 감소는 길이가 아니라 **진폭**을 줄인다) |
| 알 수 없는 mood · 3D 실패 · 폴백 | 해당 mood 의 **같은 숫자** |

> `undefined` 를 반환하면 `setTimeout(fn, undefined)` 가 되어 피드백이 **즉시** 열리고
> 반응 연출이 통째로 사라진다. 그래서 `0` 을 반환하는 경우가 하나도 없다.
> **모션 감소에서 `0ms` 로 가지 않는다** — 02 §9 의 `react()→0` 규정은 폐기한다(04 §13.3 답 4).

**이 숫자는 타이머용이지 완료 콜백이 아니다.** Court 는 Promise·완료 이벤트·`onDone` 을 제공하지 않는다.
**ui.js 는 이 값을 피드백 *표시* 시간으로 쓰지 않는다** — 피드백은 '다음'을 누를 때까지 남는다.
반환값은 **반응 → 피드백 사이의 지연**일 뿐이다.

### 8.4 `setPose(name)` → `void`

애니메이션 없이 **즉시** 포즈를 확정한다. 소리를 유발하는 임팩트를 재생하지 않는다.

| `name` | 뜻 | 쓰는 시점 |
|---|---|---|
| `'idle'` | 대기 자세 | 시작·로비·'다음 사건' 직후·결과 화면 |
| `'ready'` | 학생 쪽을 보는 주목 자세 | 사건 화면 진입(`ask`) |
| `'review'` | 정지한 중립 검토 자세 | **완료 사건 재방문** · `lock→feedback` 복구 승격 |

**`'review'` 는 일치/불일치를 구분하지 않는다.** 재방문에서 도장 소리나 지휘봉 타격을 반복시키지
않기 위해서다(R10, 06 §3-7). 판정은 DOM(`#nz-fb-verdict`)이 이미 말하고 있다.

**이름 목록은 고정이다(R9).** `'approve'` / `'rebut'` 를 포즈 이름으로 추가하지 않는다.
요구 §5 의 "기본 대기 / 정답 승인 / 오답 반박 상태가 시각적으로 구분되어야 한다"는
연출이 끝난 **정지 상태**에서도 지켜져야 하지만, 그것은 `react()` 가 끝나는 순간
Court 내부에서 기준 자세를 승인·반박 잔류값으로 바꾸는 것으로 해결한다
(`court3d.js` 의 `REST` / `restPose()`, 폴백은 `rest-approve` / `rest-rebut` 클래스).
**ui.js 는 자세를 지시하지 않고 연출 길이도 모른다** — 계약 §15 / R9 그대로다.

### 8.5 `setScene(name)` · `resize()` · `pause()` / `resume()` · `dispose()`

| 메서드 | 시맨틱 | 폴백에서 |
|---|---|---|
| `setScene('start'\|'lobby'\|'case'\|'result')` | 카메라/구도 프리셋 교체 + 내부 `resize()`. **이동 조작·공간 탐색 없음** | `#nz-fb-bust` 의 위치 클래스만 교체 |
| `resize()` | `#nz-gl` 의 `getBoundingClientRect()` 만 읽는다. `window.innerWidth` 금지. 높이 < 90px 이면 렌더 정지 | no-op에 가깝지만 호출 가능 |
| `pause()` / `resume()` | rAF 루프 정지/재개. 결과 화면·`visibilitychange`(hidden)·밴드 높이 0 | 장식 애니메이션 정지/재개 |
| `dispose()` | rAF 취소, 모든 리스너 해제, geometry/material/texture `.dispose()`, `renderer.dispose()` + `forceContextLoss()`, `#nz-fb-bust` 제거, `ok=false` | 요소 제거 |

`init()`/`dispose()` 20회 반복에 WebGL 컨텍스트가 새지 않는 것이 기본 검증 항목이다.

### 8.6 구현하지 않는 것 (R3)

`setFiles()` · `highlightFile()` · `nz:anchors` CustomEvent · `THREE.Raycaster` 로 클릭 받기 ·
`nz:impact` CustomEvent · `pulse()`.
**로비의 입력 권한은 DOM 버튼이 독점한다.** 3D 의 사건 파일 더미는 소품이고, 로비에서 캔버스는
`rgba(10,16,32,.72)` 스크림 뒤의 배경이다.

### 8.7 `data-three` 의 주인

| 시점 | 쓰는 쪽 |
|---|---|
| 부팅 | `boot.js` 가 `Court.init()` 반환값으로 `on`/`off` |
| 런타임 컨텍스트 소실/복구 | `court3d.js` 가 `off`/`on` (소실을 아는 모듈이 Court 뿐이다) |

둘 다 같은 속성에 같은 값을 쓰므로 멱등이다. **이것이 court3d.js 가 `#nz-root` 를 만지는 유일한 경우다.**

### 8.8 3D 쪽 고정 사항 (06 §2-3 [심각] 포함)

- **노직은 판사석이 아니라 칠판 앞 교탁에 선다.** 판사석·법대를 만들지 않는다.
- **카메라 시선 높이는 노직과 수평.** 올려다보는 앵글 금지. 오답 반응에서도 내려다보는 각도로
  전환하지 않고, 학생 쪽으로 전진(dolly-in)하지 않는다.
- 지휘봉은 **사람을 때리지 않는다.** 칠판·책상만 친다. 학생 모욕·체벌 연출 금지.
- **3D 캔버스 안에 글자를 굽지 않는다.** 도장에도 글자를 새기지 않는다.
- 성능 상한: draw call ≤ 24, 삼각형 ≤ 12,000, 픽셀 ≤ 2,200,000,
  DPR 상한 `split/stack 1.50`, `overlay 1.25`. 그림자·후처리 남용 금지.
- three.js **r134**. `CapsuleGeometry`/`OrbitControls`/`EffectComposer`/`BufferGeometryUtils`/
  `outputColorSpace`/`SRGBColorSpace`/`texture.colorSpace` **없다.** `renderer.outputEncoding = THREE.sRGBEncoding` 을 쓴다.

## 9. `NZ.Audio`

```js
NZ.Audio.init()              // -> void     구독만. AudioContext 를 만들지 않는다
NZ.Audio.enabled             // boolean     현재 켜짐 여부 (기본 false)
NZ.Audio.setEnabled(bool)    // -> boolean  실제 적용된 값. 사용자 제스처 안에서 호출되어야 한다
NZ.Audio.play(name)          // -> void     name 이 목록에 없으면 조용히 무시
```

| 항목 | 값 |
|---|---|
| 기본값 | **OFF** (`enabled === false`) |
| `AudioContext` 생성 시점 | **사용자가 소리를 켜는 그 클릭/키 입력 안에서만.** 그 전에는 생성하지 않는다 |
| 자동 재생 | **없음.** 페이지 로드·화면 전환·타이머에서 소리가 나지 않는다 |
| 음원 | **WebAudio 합성만.** 오디오 파일 0개, 외부 URL 0개, `fetch` 0회 |
| 최대 길이 | 220ms |
| 최대 피크 | −18 dBFS. 마스터 게인 상한 `0.22` |
| 금지 | 비명, 경보, 급격한 어택의 저음, 놀래키는 소리 |
| 실패 | `AudioContext` 생성 실패·`play()` 예외는 전부 삼킨다. **게임은 멈추지 않는다** |

**사운드 이름 — 정확히 4개**

| `name` | 쓰는 시점 | 성격 |
|---|---|---|
| `'open'` | 로비에서 사건 카드 열기 | 종이/서랍, 짧은 노이즈 버스트 |
| `'pick'` | 선택 확정 | 짧은 클릭 |
| `'match'` | 노직의 판단과 일치 — 도장 | 낮은 '탁' + 짧은 리버브 |
| `'rebut'` | 노직의 판단과 다름 — 지휘봉 | 나무 두드림. **깜짝 놀라지 않는 레벨** |

**호출은 ui.js 만 한다.** court3d.js 는 소리를 내지 않고 이벤트도 던지지 않는다(§8.6).
ui.js 는 `Court.react()` 를 부르는 **같은 줄**에서 `Audio.play('match'|'rebut')` 를 부른다.

상태 원본은 `NZ.State.muted()` 이고, `#nz-root[data-sound]` 와 `#nz-btn-mute[aria-pressed]` 는
ui.js 가 함께 갱신한다. 초기 상태: `muted=true` → `enabled=false` → `data-sound="off"` → `aria-pressed="false"`.

### 10.1 전이 규칙

1. **T10 이 이 게임의 심장이다.** '다음 사건'은 로비를 거치지 않는다.
   `nextUnanswered` 는 `CASES` 배열 순서로 현재 다음부터 **순환** 탐색해 `done` 이 아닌 첫 사건을 준다.
   7번을 먼저 열었으면 8·9·10 → 1·2… 순으로 돈다.
2. **T9 는 자동 전이지만 T10/T11 은 절대 자동이 아니다.** 타이머로 피드백을 닫는 코드를 쓰지 마라.
3. **T11 의 버튼은 T10 과 같은 엘리먼트다.** `#nz-btn-next` 의 `data-action` 이 `next ↔ result` 로
   바뀌고 라벨만 갈린다(`COPY.feedback.btnNext` / `btnResult`). 새 버튼을 만들지 않는다.
4. **T7 은 `#nz-btn-restart` 를 `result` 에서 보이지 않게 한다**(06 §4-5). 재시작 경로는 lobby/case 뿐이다.

### 10.2 입력 잠금 — 네 겹

| 겹 | 위치 | 막는 것 |
|---|---|---|
| ① 동기 플래그 `busy` | ui.js | 같은 틱·연속 틱의 두 번째 `click` |
| ② 무장 지연 `ARM_MS=150` | ui.js | '다음 사건' 더블클릭의 두 번째 클릭이 **다음 사건의 선택지**에 떨어지는 것 |
| ③ 위상 가드 `State.phase()!=='ask'` | ui.js | 피드백/반응 중에 날아온 키 입력 |
| ④ 상태 레벨 단일화 `answer()` | state.js | ①②③이 전부 뚫려도 **채점은 절대 두 번 되지 않는다** |

추가로 **`NEXT_ARM_MS=600`**: 피드백이 표시된 뒤 0.6초 동안 `#nz-btn-next` 의 클릭/Enter 를 무시한다
(06 §4-3). 버튼은 **숨기지 말고 보이게 두되** 이벤트만 무시한다 — 어디를 눌러야 하는지 모르는 게 더 나쁘다.

구현 세부:

- **`click` 만 바인딩한다.** `pointerdown`+`click` 을 같이 걸면 터치에서 두 번 발화한다.
- **키보드는 `keydown` + `if (e.repeat) return;`**.
- **`disabled = true` 를 반드시 쓴다.** `pointer-events:none` 만으로는 키보드 활성화를 못 막는다.
- **`dblclick` 을 바인딩하지 않는다.**
- **선택지와 `#nz-btn-next` 는 같은 화면 좌표를 공유하지 않는다.**

### 10.3 엣지 케이스

| 상황 | 동작 |
|---|---|
| 선택지 연타 10회 | 1회만 채점. `answer()` 가 `accepted:false` 반환 |
| 두 선택지 거의 동시 | 먼저 도착한 `click` 만. JS 단일 스레드라 `busy=true` 가 이미 서 있다 |
| '다음 사건' 더블클릭 | 1개만 전진 |
| 피드백 중 `1`/`2`/`A`/`B` | 위상 가드로 무시 |
| Enter 길게 누름 | `e.repeat` 로 무시 |
| 완료 사건 재방문 후 선택지 클릭 | 버튼 `disabled`. 뚫려도 `answer()` 가 `already` |
| 전부 불일치로 10개 완료 | **결과 화면에 도달한다.** 맞힐 때까지 반복 금지 |
| 9개 완료 + 1개 답만 함 | 그 사건을 열면 `feedback` 으로 열리고 즉시 `done` → 그다음 `결과 보기` |
| 마지막 사건 | **피드백이 먼저** 뜨고 같은 버튼이 `결과 보기`로 바뀐다. 반응 생략 금지 |
| WebGL 불가 / 3D 실패 | `data-three="off"`. **10개 전부 풀 수 있다** |
| localStorage 차단 | 메모리 상태로 정상 플레이. 시작 화면에 1줄 안내. 게임 중 재알림 없음 |
| `nz.progress` 손상 | `sanitize` 폐기 → 시작 화면. **콘솔 에러 0** |
| 탭 백그라운드 | rAF 정지(`Court.pause()`), 반응 타이머(`setTimeout`)는 계속 흐른다. 돌아오면 피드백이 열려 있다(정상) |
| 모션 감소 ON | `react()` 는 **그대로 숫자를 반환**한다. 위상 전이 동일 |
| 1366×768 / 좁은 화면 | 구조 불변. 본문·선택지는 줄바꿈으로 흐른다. **잘림 금지, 가로 스크롤 0** |

## 12. 키보드 맵 (전 화면)

문자 키는 **`event.code`로 판정한다**(`KeyA` `KeyB` `KeyM` `KeyR` `KeyF`).
한글 IME 가 켜져 있어도 `code` 는 바뀌지 않는다 — `event.key` 로 판정하면 한글 입력 상태에서 죽는다.
숫자는 `Digit0~Digit9` 와 `Numpad0~Numpad9` 를 **둘 다** 받는다.

| 화면 | 키 | 동작 |

| **전역** | `KeyM` | 효과음 On/Off 토글. 포커스 이동 없음. `aria-pressed` 갱신 + `#nz-live` 알림 |
| | `KeyF` | 전체화면 토글. 실패 시 조용히 무시(오류 표시 없음) |

| | `KeyR` | **`lobby`·`case` 에서만** `#nz-btn-restart` 실행(확인 모달). `result`·`start` 에서는 무시 |
| **시작** | `Enter` · `Space` | `#nz-btn-start` 실행 |
| | 그 외 | 무시 |
| **이어하기 패널** | `←` `→` | `#nz-btn-resume` ↔ `#nz-btn-fresh` 포커스 이동 |
| | `Enter` · `Space` | 포커스된 버튼 실행 |
