# 노직의 철학 법정 — 소유권리론 수업 도입 훅

마이클 샌델 『정의란 무엇인가』의 노직 지문(`외부지문 2 (handout).pdf`, **지문 3**)을
읽기 **전에** 돌리는 5분짜리 도입 자료. 외부지문 2의 **3차시**입니다.
(1차시 트롤리 문제 → https://totojunior.github.io/MSH/SR2/ · 2차시 출생 추첨 → https://totojunior.github.io/MSH/SR2/BL/ )

학생이 자극적인 가상 사건 10건을 보고 판결을 내립니다. 단, **자기 의견이 아닙니다.**

> **"네 생각을 고르는 게임이 아닙니다. 노직이라면 어떤 답을 고를지 맞혀 보세요."**

틀리면 노직이 나와서 지휘봉으로 책상을 치고 한마디 합니다. **그 한마디가 지문 힌트입니다.**
게임은 답을 주지 않고, 지문이 답할 두 질문으로 끝냅니다.

> *"Was it rightfully theirs?"* — 애초에 정당한 자기 것이었나?
> *"Was the transfer voluntary?"* — 자발적으로 주고받았나?

## 2. 수업 진행 — 5분

교사용 대사·발문·주의사항은 **[교사용-진행안.html](교사용-진행안.html)** 에 있습니다. 인쇄해서 들고 가세요.

| 시간 | 화면 | 할 일 |
|---|---|---|
| 0:00 | 시작 화면 | 아래 30초 대본을 읽고 [시작] |
| 0:30 | 사건 목록 | 학생이 원하는 파일부터 클릭. **순서는 상관없습니다** |
| 0:35 | 사건 → 판결 → 노직의 반응 | 사건당 20~25초 × 10건. **이 구간에 개입하지 않습니다** |
| 4:30 | 결과 화면 | 두 질문이 뜹니다. 함께 소리 내어 읽습니다 |
| 5:00 | — | 지문을 폅니다 |

### 게임 전 30초 — 그대로 읽으면 됩니다

> **①** 오늘 지문 주인공 이름은 **노직**입니다. 지금은 아무것도 안 알려줄 거예요.
>
> **②** 화면에 사건 10개가 뜹니다. **여러분 생각을 묻는 게 아닙니다.**
> **노직이라면 뭐라고 할까** — 그걸 맞히는 겁니다.
>
> **③** 틀려도 됩니다. 틀리면 노직이 나와서 한마디 하는데, **그 한마디가 오늘 지문 힌트예요.**
>
> **④** 다 못 풀어도 됩니다. 소리는 꺼져 있습니다. **그대로 두세요.** 시작.

### 게임 중 — 하지 말아야 할 것

| 상황 | 하지 말 것 | 대신 |
|---|---|---|
| 처음 60초 | **아무 말도 하지 않는다** | 침묵 |
| "답이 뭐예요?" | 답하지 않는다 | *"화면이 알려줄 거야. 눌러봐."* |
| 오답 대사에 웃음이 터질 때 | "조용히 해"라고 하지 않는다 | 그냥 둔다. 그 웃음이 대사를 기억에 박는다 |
| 05·08에서 학생이 흥분할 때 | **정치 얘기로 받지 않는다** | *"그건 지문 읽고 다시 하자."* |
| "선생님은 어느 쪽이에요?" | **표명하지 않는다** | *"나중에. 지금은 노직이 뭐라 할지만."* |
| 누구든 | **점수를 소리 내어 부르지 않는다** | 한 번이라도 부르면 경쟁 게임이 된다 |

> **2차시(롤스)와 대칭을 지킵니다.** 2차시가 *"그러니 도와야 한다"* 로 끝나지 않았듯이,
> 3차시는 *"그러니 세금은 다 부당하다"* 로 흘러가지 않게 합니다.
> 지문의 노직이 반대하는 것은 **재분배 과세**이지 모든 국가 활동이 아닙니다.
> **사건 04가 안전장치입니다** — 최소 국가는 **사기로부터 사람들을 보호합니다.** 학생이 튀면 04를 가리키세요.

### 게임 후 30초 — 지문으로

> **①** (경쟁 차단) **"몇 개 맞혔는지는 안 물어볼게요."**
> **②** "화면에 영어 질문 **두 개** 보이죠. 소리 내서 읽읍시다."
> **③** "**애초에 정당한 자기 것이었나. 자발적으로 주고받았나.** 10개 사건이 전부 이 두 개에서 갈렸습니다."
> **④** "그 아래 **justice in initial holdings / justice in transfer**.
> **지문 셋째 문단에 이 두 단어가 그대로 있습니다. 펴서 찾으세요. 찾으면 밑줄.**"
> **⑤** ### **"노직의 답에 동의하지 않아도 괜찮습니다. 이제 지문에서 그의 판단 기준을 찾아봅시다."**

⑤ 다음에 **아무 말도 덧붙이지 않습니다.** 여기서 끝입니다.

> ⚠️ 화면의 두 영어 질문은 **지문에 그 문장 그대로는 없습니다.** 기억용 요약입니다.
> 지문에서 실제로 찾을 문자열은 **`justice in initial holdings`** 와 **`justice in transfer`** 이고,
> 이 둘은 셋째 문단에 글자 그대로 있습니다. 결과 화면이 그 두 덩어리를 함께 띄웁니다.

## 3. 사건 10건

| # | 제목 | 노직의 판단이 걸리는 지점 |
|---|---|---|
| 01 | 평생 게임만 했는데 상속 100억 | Voluntary transfer — 받은 사람의 노력이 아니라 이전의 자발성 |
| 02 | 부자 돈 훔쳐서 장학금 10억 | Was it rightfully theirs? — 좋은 결과가 부당한 취득을 씻지 않는다 |
| 03 | 춤 10초에 3억 | How did they get the money? — 격차의 크기가 아니라 이동 과정 |
| 04 | 짝퉁 300만 원, 결제는 네가 눌렀잖아? | Protect people against fraud — **최소 국가도 사기는 막는다** |
| 05 | 기부 0원, 슈퍼카 30억 | Helping should not be forced — 인성 평가와 재산권 판단은 다르다 |
| 06 | 월급 250만 원, 억만장자에게 300만 원 선물 | Gifts voluntarily given — 받는 쪽이 부자라도 자발적 증여다 |
| 07 | 상속 100억, 아빠가 도둑이었다 | Justice in initial holdings — 이전이 자발적이어도 출처를 본다 |
| 08 | 찬성률 99%, 부자 한 명 재산 나눠 갖자 | Consent matters — 다수결이 소유자의 동의를 대신하지 못한다 |
| 09 | 원가 3천 원 티셔츠, 판매가 100만 원 | Free exchange — 비싼 거래와 속임수가 있는 거래는 다르다 |
| 10 | 한 명은 1억, 한 명은 0원, 그냥 반반 | Equality can be fair, too — **평등한 결과도 과정이 정당하면 정당하다** |

**대조쌍이 이 활동의 뼈대입니다.** 01↔07(정당한 상속 vs 훔친 돈 상속),
04↔09(사기 vs 비싸지만 정직), 05↔10(강제 재분배 vs 자발적 반반).
학생이 "훔친/속인 단어가 보이면 아닌 쪽"이라는 규칙만 찾아도 괜찮습니다 — **그 규칙이 곧 지문의 기준입니다.**

> 사건과 대사는 **이 지문에 근거한 수업용 창작**입니다. 노직의 실제 발언이 아니고,
> 한국 법률상 합법·불법 판정도 아닙니다. 화면에도 그렇게 적혀 있습니다.

## 4. 이 자료가 하지 않는 것

요구사항에서 명시적으로 금지된 것들이고, 코드와 테스트가 이를 강제합니다.

- **'정답 / 오답'이라고 쓰지 않습니다.** 화면 표기는 **'노직의 판단과 일치 / 다름'** 뿐입니다.
  게임이 노직을 옳다고 선언하지 않습니다. 이해하는 것과 동의하는 것은 다릅니다.
- **점수를 성향으로 읽지 않습니다.** 결과 화면에서 두 질문이 점수보다 위에 있고,
  점수 옆에는 *"노직에게 얼마나 동의하는지를 재는 점수가 아닙니다"* 가 붙습니다.
  등급·순위·비교·공유 기능이 없습니다. "롤스가 좋아합니다" 류 문구도 없습니다.
- **틀린 학생을 몰아붙이지 않습니다.** 지휘봉은 책상과 칠판만 칩니다. 사람을 때리지 않습니다.
  **연속으로 틀릴수록 반응이 조용해집니다.** 맞힐 때까지 반복시키지 않습니다.
- **5분이 지나도 자동 종료하지 않습니다.** 시간은 경과 시간으로만 보여 줍니다.
- 마지막 동의/비동의 설문은 **선택**입니다. 채점하지 않고, 고른 답이 화면에 남지 않습니다(옆자리에서 보입니다).

## 5. 내용을 고치고 싶을 때

### 사건·대사 고치기 — `src/cases.js` 한 파일

사건 10건의 **제목·상황·훅 대사·선택지·노직의 예상 답·이유·오답 대사·영어 개념**이 전부 여기 있습니다.
github.com 웹 편집기에서 고쳐도 됩니다 — **저장하면 GitHub Actions가 페이지를 다시 구워 줍니다.**

```js
{
  id: 'c01',                       // 바꾸지 마세요. 저장된 학생 기록이 이 ID를 씁니다
  title: '평생 게임만 했는데 상속 100억',
  situation: [                     // 한국어 2~3문장. [[...]] 로 감싼 부분이 화면에서 강조됩니다
    '25세 준호는 일해 본 적도 없이 하루 종일 게임만 한다.',
    '아버지가 [[정당하게 사업해서 번]] 100억을 준호에게 [[자발적으로]] 물려줬다.'
  ],
  hook: '노력? 그걸 왜 해? 아빠가 했잖아.',
  options: [                       // 정확히 2개. id 는 위치가 아니라 내용으로 짓습니다
    { id: 'c01-effort', text: '자기 노력으로 번 돈이 아니라면 가질 권리가 없다.' },
    { id: 'c01-gift',   text: '정당한 재산을 자발적으로 받았다면 가질 권리가 있다.' }
  ],
  answerId: 'c01-gift',            // 채점은 오직 이 ID로. 선택지 순서와 무관합니다
  reason: '수령자의 노력보다 재산의 출처와 자발적인 이전이 핵심이다.',
  wrongLine: '얄미운 건 알겠는데, 얄밉다고 소유권이 없어지진 않거든?',  // 이 사건 전용
  concept: 'Voluntary transfer.',
  conceptKo: '자발적 이전'
}
```

- `[[ ]]` 는 **판정을 좌우하는 조건**에만 쓰세요. 사건당 2~3개. 남발하면 강조가 죽습니다.
- **모든 강조는 같은 색입니다.** '정당하게'는 초록, '훔친'은 빨강 식으로 나누면 그게 정답표가 됩니다.
- 상황문은 20~25초 안에 읽을 분량(70~90자)으로. 단, **판정에 필요한 조건을 지우는 축약은 하지 마세요.**

### 그 외 문구 고치기 — `src/copy.js`

화면에 나오는 모든 한국어·영어 문구, 그리고 **노직의 정답 반응 대사 풀**(10개)이 여기 있습니다.
`[고정]` 주석이 붙은 문구(결과 화면 3종, 시작 안내문, 두 질문, 교사 연결 문구)는 테스트가 검사합니다 — 바꾸면 빌드가 막힙니다.

### 고친 뒤

github.com에서 고쳤다면 아무것도 안 해도 됩니다. 로컬에서 고쳤다면:

```bash
node SR2/NZ/src/test/run.js      # 콘텐츠·상태·채점 검사 80항목
node SR2/NZ/src/assemble.js      # src/ → index.html 다시 굽기
node SR2/NZ/src/serve.js         # http://127.0.0.1:8767/ 에서 확인
```

## 6. 기술 메모

| | |
|---|---|
| 배포 | `index.html` **하나**. GitHub Pages가 그대로 서빙합니다 |
| 빌드 | `src/` 의 모듈 10개 + three.js r134를 이어붙인 단일 파일 (`src/assemble.js`) |
| 자동 리빌드 | `src/` 가 바뀌면 `.github/workflows/nz-build.yml` 이 다시 굽고 커밋합니다 |
| 3D | three.js **r134** (`src/vendor/`). 인라인되어 오프라인 작동 |
| 외부 요청 | 구글 웹폰트 **1건뿐**. 실패해도 대체 폰트로 작동 |
| 의존성 | **없음**. node 외에 설치할 것이 없습니다 |
| 저장 | localStorage `nz.progress`(진행) / `nz.prefs`(소리·모션). 실패해도 게임은 작동 |

### WebGL이 없는 기기

3D가 안 되면 **같은 API를 가진 2D 화면으로 자동 전환**됩니다.
SVG로 그린 노직이 칠판 앞에 서고, 대기·승인·반박 3상태가 그대로 구분됩니다.
**사건 10건을 전부 풀 수 있고 결과 화면까지 갑니다.** 화면 아래에 그 사실을 한 줄로 알립니다.

### 접근성

- 마우스 없이 **키보드만으로** 끝까지 갈 수 있습니다 (숫자키로 사건·선택지 선택, Enter로 다음, Esc로 목록).
- 일치/불일치를 **색으로만 구분하지 않습니다** — 아이콘(✓ / ≠)과 글자가 함께 붙습니다.
- 피드백은 `aria-live` 로 낭독되고, 3D 캔버스는 `aria-hidden` 입니다.
- `prefers-reduced-motion` 을 따릅니다. 그 상태에서도 승인과 반박은 구분됩니다.
- 소리는 **기본 꺼짐**입니다. 자동 재생되는 소리가 없습니다.

### 설계 기록

`docs/` 에 설계 근거와 검토 기록이 있습니다 — 요구사항 원본, 지문 원문,
화면 흐름·상태 기계, 3D 연출 명세, 레이아웃·접근성, 수업 운영·타이밍,
**교실 리스크 검토**(소재 적절성·정치적 중립성·오답 대사 톤·학생 반응 예측), 구현 계약.
