## 한 장으로 줄이면

- **결론은 "운이다"에서 멈춘다.** 다음 차시 노직이 정확히 그걸 반박하므로, 도입에서 결론을 박으면 그 시간이 죽는다.
- **'운'이라는 단어를 결론 자리에 쓰지 않는다.** "다 운이다"는 롤스가 아니라 운평등주의(드워킨·코헨)다. 롤스 원문은 `arbitrary from a moral point of view`.
- **이 활동을 '무지의 베일'이라 부르지 않는다.** 추첨은 확률을 주는데 롤스는 원초적 입장에서 확률 계산을 금지했다(*TJ* §26·§28). 확률 모델은 하사니의 것이고 공리주의를 도출한다.
- **계층은 국가와 독립으로 뽑는다.** 국가 평균으로 채우면 같은 나라 카드가 전부 똑같아져 "저 나라는 다 가난"을 화면이 확정한다. 이게 놀림 방지의 핵심 기제다.
- **종교 이름은 사람이 아니라 나라에 붙는다.** 33장 그리드와 집계에는 종교가 아예 없고, 교사가 연 카드 1장에만 뜬다.
- **지도는 정적면적 투영.** 흔한 투영은 아프리카를 작게 만들어 주장을 갉는다.
