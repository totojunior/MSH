# 진행 타이밍 검토

3~5분 안에 끝난다 — 오히려 **너무 빨리 끝난다.** 실측 대본 기준 핵심 시퀀스는 **1분 39초**, 다시 뽑기 1회를 포함해도 **2분 19초**다. 따라서 진짜 리스크는 초과가 아니라 **미달**이고, 남는 1~2분을 미리 배정해두지 않으면 교사가 그 공백을 말로 채우다가 BRIEF가 금지한 "그러니 도와야 한다" 결론으로 새게 된다. 남는 시간은 (a) 다시 뽑기 1회 40초, (b) 학생 질문 2개 60초 + 정해진 회피 대사("그건 오늘 지문이 답한다")로 미리 못박아라. 화면 구성은 **1920×1080 고정 설계 + `--u: min(100vw/1920, 100vh/1080)` 스케일 단위**(원격데스크톱·125% 배율·비전체화면 전부 방어)로, **6열×6행 그리드(36칸, 카드 305×108px)**를 쓴다. 그리고 결정적 결론 하나: **"33장 한 화면"과 "항목 7~8개 전부 판독"은 양립하지 않는다.** 픽셀이 아니라 시각(arcmin) 문제다 — 7.5m 뒷줄에서 22px 텍스트는 6.3 arcmin으로 물리적으로 못 읽는다. 절충은 **역할 분리**다: 그리드 카드는 **국가명(46px)** 과 **계층 막대(108×14px, 텍스트 아님)** 만 뒷줄까지 전달하고 — 막대는 길이로 읽히므로 42 arcmin, 뒷줄에서도 "같은 나라인데 막대가 다르다"가 보여서 BRIEF의 놀림 방지 효과가 그리드에서 실제로 작동한다 — 나머지 6개 항목은 하단 **스포트라이트 3장(교사 낭독용 큐카드)** 에 몰아넣는다. 뒤에서 못 읽는 건 교사가 소리 내어 읽으면 되고, 청각은 거리와 무관하다. 하단 집계의 마지막 한 방은 "한국 0명"이 아니라 **"한국만큼 잘사는 나라에서 태어난 사람 2 / 33" 바로 아래 붙는 "지금 이 교실 33 / 33"** 이다. 다시 뽑기 버튼은 **필요하다. 단 1회로 하드 제한**하라 — 2회차는 "재현 안 됨 = 운"을 증명하는 최강의 교육적 순간이지만 3회차부터는 "한국 나올 때까지 돌리기" 가챠가 되어 메시지가 정확히 반대로 뒤집힌다. 버튼이 스스로 사라지면 교사가 아니라 화면이 거절하는 것이 되어 교실 권력 관계가 깨지지 않는다.

6. 애니메이션 타임라인 (총 5.62초)
═══════════════════════════════════════════════════════════
  카드 i (0..32) 시작시각:
     t_i = 3400 × (i / 32) ^ 0.78   [ms]
  → 감속 스태거. 첫 간격 228ms(하나… 둘… 셋…), 마지막 간격 83ms(우수수 쏟아짐).
     실제 값: t1=228 t2=391 t3=537 t5=799 t10=1372 t16=1980 t24=2717 t32=3400
  카드 개별 애니: 260ms, cubic-bezier(.2,.8,.2,1)
     opacity 0→1, transform: translateY(10px) scale(.94) → none
     will-change: transform,opacity 를 시작 시 부여 → 끝나면 제거
     box-shadow / filter / blur 애니메이션 절대 금지 (구형 교실 PC GPU)

  0     ms  버튼 클릭. 36칸 빈 슬롯은 이미 화면에 있음 → 시프트 0
  0–3660    카드 33장 (마지막 카드 정착 3400+260)
  3660–4100 정적 440ms  ← 침묵. 애들이 화면을 훑는다. 웅성거림이 여기서 시작된다.
  4100 / 4280 / 4460  스포트라이트 3장 (각 320ms, 180ms 간격)
  4780      집계 [좌] 한국 0명   (240ms + 숫자 스냅 scale 1.25→1, 180ms)
  5080      집계 [중] 기대수명
  5380      집계 [우] 2/33 → 100ms 뒤 "지금 이 교실 33/33" 별도 페이드
  5620 ms   종료. 이후 정지. 자동 진행 없음.

9. 항목 7~8개 vs 33장 — 양립 판정
═══════════════════════════════════════════════════════════
  판정: **양립 불가.** 물리적 근거 —
   33장 그리드에서 카드 1장의 세로 예산은 최대 166px(9열×4행 기준)이다.
   항목 8개를 뒷줄 판독선(12 arcmin@7.5m/75" = 40px)으로 쓰면 8×46 = 368px가 필요하다.
   166 < 368. 어떤 배열로도 불가능. 카드를 전체화면으로 키우면 되지만
   그건 BRIEF가 금지한 "단계"다.

  채택한 절충 = **역할 분리 (3층 구조)**
   L1 뒷줄까지  : 국가명 46px + 계층 막대(길이 부호)          [그리드 33장]
   L2 앞3줄까지 : 교육·가정 22px + 스포트라이트 8항목 22px     [그리드 + 스포트라이트]
   L3 전원      : 교사 육성 낭독 — 스포트라이트 3장을 소리로 읽는다. 거리 무관.
                  + 집계 96px 숫자
  즉 "항목 7개"는 **눈이 아니라 귀로** 전달한다. 스포트라이트 3장은 학생용 디스플레이가
  아니라 교사용 프롬프터다. 이 정의를 명확히 하면 22px가 작다는 게 결함이 아니라 설계다.
