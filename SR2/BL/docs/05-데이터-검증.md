■ 판정 1 — 계층은 **합격**. 훌륭하다.
  미국 안에서 18,000원↔31만원(17배), 인도 안에서 5,200원↔28,000원(5.4배).
  그리고 "미국 하위 3%(18,000원) > 인도 중간(13,000원)"이 저절로 보인다.
  국가 간 격차와 국가 내 격차가 동시에 화면에 뜬다. 브리프 요구를 정확히 충족.

■ 판정 2 — 교육은 **불합격.** 두 가지가 동시에 깨진다.
  (a) 가드가 p≥0.90에서만 발동해서 **p=0.88이 그냥 통과한다.**
      "미국 · 상위 12% · 중학교까지", "인도 · 상위 12% · 초등학교까지"가 실제로 나온다.
  (b) 더 근본적으로 **분포 자체가 틀렸다.** N=40,000 실행 결과:
        모델 고교미졸    실측(OECD 25-34세)   실측(WB 25세+)
        한국 22.4%       1%                   18.5%
        미국 34.7%       6%                   8.4%
        일본 21.5%       —                    14.8%
        독일 26.9%       —                    18.1%
        영국 18.1%       —                    19.5%
      카드는 "지금 태어나는 아이"인데 모델 출력은 25세+ 재고(=1950년대에 교육받은
      노년층 포함)에도 못 미치고 그냥 틀렸다. 특히 **미국이 4배 틀렸다.**
      원인: sE = 2.0+0.22(14−eyrs)가 한국에 sd 2.09를 준다.
      평균 13.59, sd 2.09 → P(<12) = Φ((12−13.59)/2.09) = Φ(−0.76) = 22.4%. 정확히 재현됨.
      HCI 기대교육연수는 학력 "분포"가 아니라 상한 14로 잘린 단일 기대값이라
      정규분포를 얹는 순간 선진국 하단이 통째로 허구가 된다.
      ▶ 교실 리스크: 33명 중 7~8명이 "고등학교 중퇴/중학교까지"로 뜨는데 그중 한국·미국
        카드가 섞인다. 고2가 "미국이 왜 저래요?"라고 물으면 답이 없다. 반드시 고친다.

■ 판정 3 — 건강은 **조건부 합격, 라벨은 불합격.**
  방향(-RHO_H·z)은 맞다. 부자일수록 zH가 낮아져 덜 아프다.
  그러나 p_weak의 원자료는 **5세미만 발육부진율(stunting)** = 출생 후 영양결핍 결과다.
  이걸 "약하게 태어남"으로 표기하면 원인을 출생으로 돌리는 **사실 왜곡**이다.
  게다가 명세는 "약하게 태어남", 참조구현은 "자주 아픔", 목업 veil.html은 "몸이 약함"
  — 세 문서가 다 다르다.

■ 판정 4 — labClass에 **표기 버그**가 있다.
    p=0.4999 → "하위 50%"     p=0.5000 → "상위 50%"
  거의 같은 사람이 정반대로 읽히고, **"하위 50%"와 "상위 50%"가 같은 화면에 공존**한다.
  더 큰 문제: p가 0.35~0.65인 카드가 전체의 **30.0%**인데 전부 "하위 43%" "상위 45%"처럼
  뜬다. 고2에게 "하위 47%"는 "못사는 쪽"으로 읽히지만 실제로는 중간이다.

■ 판정 5 — 소득 하단 꼬리가 **비물리적**이다.
  "하루 100원"(=$0.13/일) 카드가 0.08%, "하루 500원 미만"이 0.82% 나온다.
  33명 반당 0.27장 → 하루 11개 반이면 약 3장이 뜬다.

    const t  = clamp((14 - c.eyrs)/8, 0, 1);  // 가난할수록 1
    const w0 = 0.45*t*t, w1 = 0.35*t;         // 못감 / 초등 비중
    return [ Bm*w0,                                   // < : 학교에 못 감
             Bm*(w0+w1),                              // < : 초등학교까지
             Bm*(w0+w1+(1-w0-w1)*0.55),               // < : 중학교까지
             Bm,                                      // < : 고등학교 중퇴
             1 - Math.min(TB, HS*0.98) ];             // < : 고등학교 졸업 / else 대학 이상
  }
  // 카드 생성
  const rhoE = clamp(0.55 + 0.006*(c.gini - 30), 0.30, 0.75);
  const zE   = rhoE*z + Math.sqrt(1 - rhoE*rhoE) * gauss(rnd);

  const k    = eduCuts(c);
  const lvl  = q<k[0]?0 : q<k[1]?1 : q<k[2]?2 : q<k[3]?3 : q<k[4]?4 : 5;
  const LAB_EDU = ["학교에 못 감","초등학교까지","중학교까지",
                   "고등학교 중퇴","고등학교 졸업","대학교 이상"];
  ※ 성별격차: 여자면 q를 eyrs_gap에 비례해 이동

## 주의
- 교육 보정 모델(§5.4)은 내가 프로토타입으로 만들어 14개국 N=200,000씩 검증한 것이지, 프로젝트 파일에 반영하지는 않았다. build_card_stats.py에 SE.TER.CUAT.BA.ZS 수집 두 줄과 edu_hs/edu_ter 필드를 추가해야 동작한다. 검증 스크립트는 스크래치패드에 남겨 뒀다.
- edu_hs/edu_ter는 25세 이상 '재고'다. 카드가 표현하는 건 지금 태어나는 아이의 미래 학력이므로, 엄밀히는 25-34세 코호트 값이 맞다(한국 25+ 18.5% vs 25-34세 1%). 다만 25-34세 값은 World Bank API에 전 국가로 존재하지 않는다. 25+ 값을 쓰면 최소한 '인용 가능한 공식 숫자'가 되고 현행 대비 미국 오차가 4배에서 0으로 줄어든다. 이 한계는 교사에게 알려야 한다: 화면 문구는 '이 33명 중'으로만 쓰고 '세계 실제로'라고 쓰지 말 것.
- 북한 edu_hs=0.75는 내 판단이지 실측이 아니다. 북한은 12년 의무교육·초등 수료율 100%가 보고되지만 고졸 이상 비율의 신뢰할 만한 수치는 없다. '가장 덜 틀린 값'이고 est에 manual로 기록해야 한다. 대안으로 북한을 아예 추첨 풀에서 빼는 선택지도 있다(출생 0.257% 손실, 브리프 방침과는 더 안전).
- 교육 컷의 하위 3구간 배분 가중치(w0=0.45t², w1=0.35t, 중학 55%)는 실측이 아니라 내가 정한 형태 파라미터다. 총량(고교미졸 비율, 대졸 비율)만 실측에 정합되고 그 안의 배분은 근사다. eyrs를 shape로 쓴다는 사실을 명세에 공개해 뒀다.
- 소득 하한 클램프(그 나라 평균의 4%, 절대 하한 300원)는 내가 임의로 정한 값이다. 로그정규 꼬리가 비물리적이라는 진단은 확실하지만(하루 100원=$0.13), 몇 원에서 자를지는 판단의 문제다. 클램프를 걸면 최하위 카드들이 같은 숫자로 뭉치므로 4%보다 낮추면 다양성이, 높이면 현실성이 는다.
- '다수:소수 = 2:1'은 실측이 아니라 설계값이다. 각주를 화면에서 빼는 순간 이 설계의 최대 방어선이 사라진다. 반드시 상시 노출(모달 금지).
- 한국어 국가명 217개는 아직 아무도 만들지 않았다. 이게 실제 구현의 첫 번째 작업이어야 한다. 카드 폭 252px·19px 글씨 기준 8자 제한은 목업 CSS에서 역산한 값이라 실제 렌더로 재확인이 필요하다.
- p_weak(발육부진 기반)은 관측치와 회귀적합치의 기하평균으로 스무딩한 '지수'라서 어떤 나라도 원자료와 정확히 일치하지 않는다. 퍼센트를 화면에 노출하지 않는 한 문제없지만, 학생이 '이 숫자 어디서 나왔어요'라고 물으면 정확한 출처를 댈 수 없는 항목이다.
- 설계안1의 'Pew 잔여 범주 개명' 문제는 47개 검증국을 넘어 나머지 147개국에도 같은 방식으로 퍼져 있을 가능성이 높다. 나는 인도·일본·중국·북한 4건만 확인했다. 출생 비중이 큰 나라부터 잔여 범주 라벨을 훑어보길 권한다.
- 교육기본법 제6조·보이텔스바흐 원칙 인용(설계안2)은 내가 원문 대조하지 않았다. 학부모·관리자 대응 문서에 쓸 거라면 국가법령정보센터에서 현행 조문을 확인할 것.
- '이슬람교가 33명 중 약 12명'이라는 기대값은 파일에서 내가 재계산해 확인한 값이다. 이 항목을 넣을지 최종 판단은 교실 실정을 아는 선생님 몫이다. ?noreligion=1 토글은 반드시 남겨 둘 것.
- 가정 항목을 개인 카드에서 빼자는 것은 내 권고다. 브리프의 지문 원문 목록에는 supportive family or a broken one이 있으므로 지문 정합성은 조금 손해다. 하단 집계 ④번 줄이 그 손해를 메우도록 설계했지만, 남기고 싶다면 라벨을 '부모님 두 분과 / 한 부모와 / 할머니·친척과' 셋으로만 하고 SEP=0.15가 출처 없는 상수라는 걸 교사가 알고 쓰면 된다.
