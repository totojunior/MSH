## 3. 화면에 뜨는 숫자는 전부 실측입니다

| 항목 | 출처 |
|---|---|
| 국가별 출생아 수 (추첨 가중치) | World Bank `SP.POP.TOTL` × `SP.DYN.CBRT.IN` (2023–24) |
| 기대수명 | World Bank `SP.DYN.LE00.IN` |
| 학력 분포 | World Bank `SE.SEC.CUAT.UP.ZS`, `SE.TER.CUAT.BA.ZS` (25세+) |
| 종교 구성 | Pew Research Center *Religious Composition 2010–2020* + CIA World Factbook |
| 국가별 이름 | 각국에서 흔한 이름 (133개국 개별, 나머지는 지역 기본값) |
| 세계지도 | Natural Earth 110m · **Equal Earth 정적면적 투영** |

- 전 세계 연간 출생아 **133,490,217명**. 한국은 **0.174%** — 33명 학급에서 **0명일 확률 94.4%**.
- 종교는 **193개국, 세계 출생아의 100%** 를 덮습니다.

### 설계상 반드시 알아야 할 것

**계층은 국가와 독립으로 뽑습니다.** World Bank에 국가 *안*의 소득 분포 자료가 없어서,
국가 평균으로 채우면 인도 카드 6장이 전부 똑같아지고 화면이 "인도는 다 똑같이 가난"을
확정해 버립니다. 국가 지표(실측)와 국가 내 위치(독립 추첨)를 분리해야
같은 인도 카드 두 장이 서로 다른 인생이 되고, 그게 "저 나라 꾸지다"는 놀림을 원천 차단합니다.

**종교 이름은 사람이 아니라 나라에 붙습니다.** 카드를 열면
"그 나라에서 가장 많은 종교 — 이슬람교 96%"라는 **국가 통계**가 뜨고,
그 사람 칸에는 "그 나라에서 다수 쪽 / 소수 쪽"만 뜹니다.
어떤 학생 이름 옆에도 종교명이 붙지 않고, 33장 그리드와 하단 집계에는 종교가 아예 안 나옵니다.
지문의 논점이 *무엇을 믿느냐*가 아니라 *다수냐 소수냐*이기 때문입니다.

> *"Some are members of racial, ethnic, or religious minorities; others, not."*

**Equal Earth 투영을 씁니다.** 흔히 쓰는 투영은 고위도를 부풀려 아프리카를 실제보다
작게 만드는데, 그러면 "출생은 아프리카·남아시아에 몰린다"는 그림 자체가 흐려집니다.
정적면적 투영이라 **화면 위 점 밀도 = 실제 출생 밀도** 입니다.

**이 활동을 '무지의 베일'이라고 부르지 마세요.** 추첨은 확률을 부여하는데
롤스는 원초적 입장에서 확률 계산을 금지했습니다(*TJ* §26·§28). 확률을 주는 모델은
하사니(Harsanyi)의 것이고 그건 공리주의를 도출합니다 — 지문 4문단이 정확히 부정하는 결론입니다.
이름은 **출생 추첨**입니다. 자세한 대응은 진행안의 "학생이 칠 만한 반박" 참고.

## 4. 고치는 법

`index.html` 은 빌드 결과물입니다. **직접 고치지 말고** `src/` 를 고친 뒤 다시 빌드하세요.

```
src/
  template.html          ← 화면·CSS·로직 전부. 대부분의 수정은 여기만 고치면 된다
  build.py               ← template + 데이터 → index.html
  build_font.py          ← Pretendard 를 필요한 글자만 잘라 base64 로
  build_names.py         ← 국가별 이름 (1차)
  build_names2.py        ← 국가별 이름 (2차 보강, 133개국)
  build_religion.py      ← Pew 원본 CSV → 종교 분포
  build_assets.py        ← 국기 216개 내려받기 + 폰트 서브셋
  data/
    cards.json           ← 국가별 출생아·기대수명·학력 (명렬표는 비어 있음)
    country_ko.json      ← 한국어 국가명 217개
    worldbank_raw.json   ← World Bank 원자료
    assets/              ← 국기·폰트·이름·종교·지도
```

### 빌드

```bash
cd src
python build.py          # template.html + data/ → ../index.html
```

`build.py` 는 두 벌을 만들도록 돼 있습니다.
공개본만 필요하면 `build('birth-lottery.html', True)` 줄을 지우고
`build('../index.html', False)` 로 바꾸면 됩니다.

폰트나 국기 데이터를 다시 만들려면 (인터넷 필요):

```bash
python build_assets.py   # 국기 216개 + Pretendard 원본
python build_font.py     # 화면에 쓰이는 글자만 서브셋
```

`template.html` 의 문구·색·크기만 고칠 거면 `python build.py` 한 번이면 끝입니다.

### 깃헙에서 바로 고치기

`src/template.html` 을 깃헙 웹 편집기로 고칠 수는 있지만, 그러면 `index.html` 이
다시 빌드되지 않아 화면은 안 바뀝니다. 파이썬을 돌릴 수 있는 곳에서 `build.py` 를
실행해 `index.html` 을 갱신해야 합니다.

## 5. 교실에서 주의할 것

진행안에 자세히 있지만, 핵심만:

- 카드가 흐르는 동안 **어떤 나라 이름도 소리 내어 읽지 않는다.** 읽는 순간 그 나라가 주목 대상이 된다.
- **"북한은 ~"으로 시작하는 문장을 만들지 않는다.** 뜨면 3초 안에 덮는다 — *"네, 저기도 아기가 태어나요. 다음."*
- **"그러니 도와야 한다"로 끝내지 않는다.** 다음 차시 노직 지문이 정확히 그걸 반박한다.
- 결론 자리에 **'운'이라는 단어를 쓰지 않는다.** "다 운이다"는 롤스가 아니라 운평등주의로 읽힌다.
- **반에 이주배경 학생이 있으면** 수업 전 쉬는 시간에 그 학생에게만 조용히 한마디. 진행안 참고.
- **[다시 한 번]은 1회까지.** 화면이 알아서 버튼을 감춘다.
