# YM 은 왜 저장소 규칙의 예외인가

> 나중에 이 폴더를 열어 보고 "규칙 위반이네" 하며 되돌리려는 사람을 위해 남긴다.
> **되돌리면 활동이 죽는다.**

## 깨는 규칙 세 개

### 1. `CLAUDE.md` §4 — "서버도 DB도 로그인도 없다"

YM 은 Supabase(PostgreSQL + Realtime)를 쓴다.

**이유**: 이 활동의 전부가 *실시간 멀티플레이*다. 33명이 같은 좌석을 동시에 누르고
정확히 한 명만 이겨야 하고, 그 사실이 나머지 32대의 화면에 즉시 반영되어야 한다.
서버 없이 이걸 하는 방법은 없다.

**그런데 개인정보 규칙은 그대로 지킨다** — 오히려 다른 차시보다 엄격하다.

| 저장하지 않는 것 | 어떻게 |
|---|---|
| 실명·학번 | 별명만. 학생이 직접 짓고 12자로 자른다 |
| 점수·등급 | 애초에 점수가 없다. 순위·비교·공유 기능도 없다 |
| 누가 무엇에 투표했는지 | `votes` 테이블에 **시각을 저장하지 않는다.** 좌석 잡은 시각과 대조하면 역추적이 가능하기 때문이다. 그리고 이 테이블은 정책도 권한도 0이라 어떤 클라이언트도 읽을 수 없다 |
| 영구 보관 | 방은 30일 뒤 만료된다. 교사가 지울 수도 있다 |

### 2. `CLAUDE.md` §4 — ES 모듈 금지 / `fetch()` 금지 / 외부 URL 금지, 그리고 `assemble.js` 단일 파일 빌드

`SR2/src/assemble.js` 는 `import` / `export` / `require(` / `fetch(` / `XMLHttpRequest` /
외부 URL 을 발견하면 **빌드를 강제로 실패**시킨다. YM 은 정의상 `*.supabase.co` 와
HTTPS·wss 로 통신하는 앱이라 그 파이프라인을 통과할 수 없다.

그래서 YM 에는 `assemble.js` 도 CI 워크플로도 없다. `index.html` / `admin.html` /
`screen.html` 이 **빌드 산출물이 아니라 원본**이고, 그대로 배포된다.

**단, ES 모듈은 결국 안 썼다.** supabase-js 를 UMD 빌드로 가져오니 모듈이 필요 없어졌고,
기존 NZ 와 똑같은 `(function(){ ... })()` + `window.YM` 네임스페이스 구조를 그대로 쓴다.
깨는 규칙이 셋에서 둘로 줄었다.

`src/serve.js` 는 남겼다. 다른 차시와 같은 이유로 — `python -m http.server` 는 charset 을
안 붙여서 한국어 로케일 브라우저가 EUC-KR 로 추측하고 본문을 깨뜨린다. 포트는 **8768**
(SR2 8766, NZ 8767 다음).

### 3. `CLAUDE.md` §1 — "인터넷이 끊긴 교실에서는 HTML 파일 하나를 받아 더블클릭한다"

YM 은 오프라인으로 못 돈다. 이건 사실이고 숨기지 않는다.

**대신 그 규칙에 대한 YM 의 답이 두 개 있고, 둘 다 선택이 아니라 필수다:**

- `screen.html?demo=1` — Supabase 에 한 번도 접속하지 않고 전 과정을 재생한다.
  숫자는 실제 리허설에서 나온 값을 그대로 옮겼다. 투표는 손을 들어서 한다.
- `교사용-진행안.html` 7절의 **종이 대체 활동** (5분) — 칠판에 좌석 13칸, 손들기 경매.

교실에서 만날 가장 흔한 고장은 버그가 아니다. **학교 프록시가 https 는 통과시키면서
wss 업그레이드만 막는 경우**, 그리고 무료 플랜 프로젝트가 며칠 놀다 잠든 경우다.
둘 다 "RPC 는 되는데 화면만 영영 안 바뀐다"는, 교실에서 가장 헷갈리는 모습으로 나타난다.
그래서 클라이언트에는 5초 안에 구독이 안 붙으면 조용히 폴링으로 내려가는 경로가 있고,
화면 구석에 `느린 연결` 배지가 뜬다.

## 지키는 규칙

깨지 않은 것들도 적어 둔다. 이건 그대로 따라야 한다.

- CSS 토큰 접두사 `--ym-*` (NZ 는 `--nz-*`, SR2 는 무접두사). 모든 자료가 같은 origin 이다
- localStorage 키 접두사 `ym.` — 없으면 앞 차시 기록을 덮어쓴다
- 색만으로 상태를 구분하지 않는다. 좌석은 색 + 빗금 + `aria-label`, 가격은 색 + 숫자
- 소리 기본 꺼짐, 자동재생 없음. 소리는 **교탁 스피커 하나**로만 난다 —
  크롬북 33대가 동시에 울리면 수업이 안 된다
- 등급·순위·비교·공유 기능 없음
- 정답을 선언하지 않는다. 화면 어디에도 "불공정하다" "암표는 나쁘다"가 없다
- 틀린 학생을 몰아붙이지 않는다. 좌석을 못 잡은 학생 화면에 빨간 실패 문구가 없다
- 저장소 파일은 CRLF (`core.autocrlf=true` 가 처리한다)
- 주석과 커밋 메시지는 한국어로, **왜** 그렇게 했는지를 남긴다
- `README.md` + `교사용-진행안.html`, 설계 기록은 `docs/`
- 새 차시를 추가했으니 `SR2/README.md` 표에 행을 넣었다
- 프레임워크·번들러·`npm install` 없음. node 와 브라우저만
