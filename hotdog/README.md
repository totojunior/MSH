# 🌭 핫도그 레이스 — 2학년 1반 추첨 앱

남는 핫도그 **10개**를 학급 **33명 중 10명**에게 토너먼트 레이스로 뽑아주는 교실 화면용 추첨 앱.

## ▶ 실행
- **온라인:** https://totojunior.github.io/MSH/hotdog/
- **오프라인:** `index.html`을 내려받아 더블클릭 (인터넷 없이도 100% 작동 — 효과음·배경음악·이름이 전부 파일 하나에 내장)

## 게임 진행
조별리그 → 준결승 → 결승 → **10명 당첨** 🏆

## 조작
| 키 | 동작 |
|---|---|
| `Space` | 시작 / 라운드 사이 다음 |
| 명단 칩 클릭 | 결석 토글 |
| 당첨 인원 입력 | 기본 10명 |
| `F` 전체화면 · `M` 음소거 · `R` 초기화 · `Esc` 중단 |

## 특징
- 단일 HTML, 완전 오프라인(외부 의존 0)
- 귀여운 핫도그 주자에 학생 이름, 카운트다운·역전·포토피니시, 색종이·골든 우승카드, 박진감 배경음악 + 효과음 10종
- 화면 크기에 맞춰 자동 레이아웃(프로젝터 친화)
