# 🌭 핫도그 레이스 — 2학년 추첨 앱

남는 핫도그를 반별로 **토너먼트 레이스**로 추첨해 나눠주는 교실 화면용 앱. **반을 골라서** 진행합니다.

## ▶ 실행
- **온라인:** https://totojunior.github.io/MSH/hotdog/
- **오프라인:** `index.html`을 내려받아 더블클릭 (인터넷 없이 100% 작동 — 효과음·배경음악·이름이 전부 파일 하나에 내장)

## 반 선택
상단 **반 선택** 버튼을 누르면 명단과 당첨 인원이 그 반으로 바뀝니다. 당첨 인원(남는 핫도그 수)은 화면에서 조절 가능.

| 반 | 명단 | 남는 핫도그(당첨 기본) |
|---|---|---|
| 2학년 1반 | 33명 | 10명 |
| 2학년 2반 | 35명 | 8명 |
| 2학년 6반 | 32명 | 8명 |
| 2학년 9반 | 28명 | 7명 |

## 게임 진행
조별리그 → (예선/준결승) → 결승 → **당첨자 발표** 🏆

## 조작
| 키 / 동작 | 기능 |
|---|---|
| `Space` | 시작 / 라운드 사이 다음 |
| 반 선택 버튼 | 반 변경 |
| 명단 칩 클릭 | 결석 토글 |
| 당첨 인원 입력 | 반별 기본값(조절 가능) |
| `F` 전체화면 · `M` 음소거 · `R` 초기화 · `Esc` 중단 |

## 특징
- 단일 HTML, 완전 오프라인(외부 의존 0)
- 귀여운 핫도그 주자에 학생 이름, 카운트다운·역전·포토피니시, 색종이·골든 우승카드, 박진감 배경음악 + 효과음 10종
- 화면 크기에 맞춰 자동 레이아웃(프로젝터 친화)
