## 사용

- 차시를 열고 시작 버튼을 누른 뒤 Space/→로 진행합니다. 장면 안의 짧은 연출만 자동 재생되며 다음 장면은 교사가 넘깁니다.
- B: 배경음만, M: 전체 소리, N: 교사 메모, F: 전체 화면, ←: 이전 장면. 교사 메모에서 전체/배경음 음량을 따로 조절합니다.
- 첫 시작 클릭 전에는 소리가 나지 않습니다. 네 차시 모두 배경음7곡을 포함하며 내레이션은 없습니다. 학생 손들기·투표·개인정보 수집도 없습니다.
- 목록으로 돌아오려면 브라우저 뒤로가기를 사용합니다.
- ‘파일 받기’로 각 HTML 하나를 미리 저장하면 인터넷 없이 실행할 수 있습니다. 그림·폰트·소리·Three.js가 모두 내장돼 있습니다.
- 4차시의 급식 시각은12:50입니다. 실제 교실 스피커·프로젝터에서는 수업 전에 음량과 가독성을 확인하세요.

## 업데이트 원칙

`1/index.html`~`4/index.html`은 검증한 완성본의 바이트를 그대로 복사한 배포 산출물입니다. 원본 src·자산·생성 프롬프트·QA·독립 Git 이력은 교사 작업 폴더 `외부지문 3 Hook`의 차시별 `제작원본`에 있습니다. 그곳에서 수정·빌드·검증한 뒤 해당 차시를 다시 복사합니다. 완성본을 이곳에서 직접 편집하지 않습니다.

이 폴더는 `Lesson3/`와 같은 완성본 가져오기 방식이며 기존 SR2 조립기/CI의 대상이 아닙니다. SR3에 이미 내장된 Three.js0.180.0과 원래 교사용 시작/소리 동작을 유지합니다. 이 저장소에서 npm 설치나 새 프레임워크는 필요 없습니다. 목록은 외부 요청 없는 단일 HTML이며, 생성 템플릿/준비 스크립트는 원본 작업 폴더 `인계기록/배포`에서 관리합니다.

`release.json`에 각 실행 파일의 크기·SHA-256·검증 원본 커밋을 기록했습니다. 워크시트 PDF, 작업 중간 파일, 소스 저장소, 이동용 ZIP은 게시 대상에 포함하지 않았습니다.
