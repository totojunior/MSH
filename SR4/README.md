# SR4 · 외부지문 4, 본문 전 5분

김종달(종달새형)·이애매(중간형)·오밤중(올빼미형)이 나오는 고2 영어 외부지문 4 지문 1~3의 교사 진행형 Hook입니다. 노트북을 TV에 연결해 교사 혼자 클릭하며 진행하고(학생 참여 없음), 편마다 약 5분 동안 그래픽·효과음·배경음으로 본문을 읽을 질문을 엽니다.

## 사용

- 수업 전: 열고 `▶ 시작` → `F`(전체 화면) → TV 볼륨 확인. 확인 뒤 새로고침(F5)으로 시작 화면에 돌려 두고, 수업 때 다시 `▶ 시작` → `F`.
- 클릭 · `→` · `Space` · `Enter` · `PageDown`: 다음 단계(연출 도중이면 끝 상태로), 다 나오면 다음 장면.
- `←` · `Backspace` · `PageUp`: 이전 장면(단계 다 펼침). 숫자(지문 1·2는 `1`~`7`, 지문 3은 `1`~`8`): 장면 이동, 같은 번호를 다시 누르면 그 장면 처음부터. `Home`: 장면 1 처음.
- `M`: 음소거, `F`: 전체 화면. `▶ 시작`을 누르기 전에는 넘어가지도, 소리가 나지도 않습니다.
- 소리는 모두 브라우저에서 합성하며 내레이션은 없습니다. 학생 손들기·투표·개인정보 수집도 없습니다.
- 1920×1080 화면 기준으로 만들었고, 다른 크기에서는 비율을 유지한 채 축소됩니다. TV에서는 `F`로 전체 화면을 쓰세요.
- 목록으로 돌아오려면 브라우저 뒤로가기를 씁니다.
- 목록의 ‘파일 받기’로 HTML 하나를 저장하면 인터넷 없이 실행됩니다. 사진·소리는 내장돼 있고, 글꼴만 구글 웹폰트라 오프라인에서는 기본 글꼴로 바뀝니다.
- 등장인물·사건은 가상이며, 마석고 시정표(지문 2)와 2026 학사일정(지문 3)만 실제 자료입니다. 사진 출처는 각 편 화면에 표기했습니다.

## 업데이트 원칙

`1/index.html`~`3/index.html`은 검증한 완성본의 바이트를 그대로 복사한 배포 산출물입니다. 원본 소스·이미지 준비 스크립트·사운드 엔진·스펙·교사용 대본은 교사 작업 폴더 `외부지문 4 Hook`의 `build/`(지문 1)·`build2/`(지문 2)·`build3/`(지문 3)에 있습니다. 그곳에서 수정·조립(`assemble.py`)·검증한 뒤 `hook.test.html`을 해당 번호 폴더의 `index.html`로 다시 복사합니다. 완성본을 이곳에서 직접 편집하지 않습니다. `.gitattributes`로 줄바꿈 변환도 막아 두었습니다.

`SR3/`와 같은 완성본 가져오기 방식이며 SR2 조립기/CI의 대상이 아닙니다. 목록 `index.html`은 손으로 쓴 단일 HTML입니다(미리보기 그림 내장, 외부 요청은 구글 웹폰트뿐).

교사용 대본(차시별 진행 멘트와 읽기 정답)은 학생도 볼 수 있는 공개 저장소라 올리지 않았습니다. 작업 폴더의 `hook_교사용_대본.md`·`hook2_교사용_대본.md`·`hook3_교사용_대본.md`를 쓰세요. `release.json`에 각 실행 파일의 크기와 SHA-256을 기록했습니다.
