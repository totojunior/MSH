# review — AI 영어 학습 도우미 (2학기)

https://totojunior.github.io/MSH/review/

교과서 영어Ⅱ Lesson 3 본문과 외부지문 3·4로 AI가 연습 문항(18유형·실전 세트)을 만들어 시험지처럼 풀고,
패러프레이즈 연습과 해석 점검을 하는 웹앱이다. 1학기 복습 도구(단일 HTML)를 이 앱으로 바꿨다.

## 이 폴더는 빌드 산출물이다

- 소스는 교사 노트북의 `AI Paraphrasing and Making Questions/app/web` (Vite + React) 이고, 서버는 Supabase 프로젝트다.
- 여기 파일을 직접 고치지 마라. 소스에서 `npm run build` 한 `dist/` 를 통째로 복사해 덮어쓴다.
- 해시 라우터(`#/login` …)와 상대 경로 빌드라서 `/MSH/review/` 아래에서 그대로 돈다.

## 교사용 사용법

1. **입장코드**: 반마다 6자리 입장코드가 있다. 학생은 로그인 화면에서 자기 반 코드를 넣고 명렬표에서 이름을 누른 뒤
   첫 방문에 비밀번호를 만든다. 코드는 관리자 설정 화면(반별 입장코드)과 각 반의 학생 목록 상단에서 보고 복사한다.
2. **교사 로그인**: 교사 카드에서 이름을 고른다. 처음이면 설정 코드와 새 비밀번호를 정하고, 그다음부턴 비밀번호만 넣는다.
   관리자는 1~11반 전체와 설정(하루 한도, 지문 공개, 입장코드, API 사용량)을, 담당 교사는 담당 반의 현황·학생 목록·
   학생 상세(비밀번호 초기화)·기록 내보내기만 본다.
3. **지문 공개**: 외부지문 3·4는 비공개로 시작한다. 진도에 맞춰 관리자 설정에서 켠다.
4. **비밀번호를 잊은 학생**: 학생 상세에서 초기화하면 다시 '처음' 상태가 되고 기록은 남는다.
5. **기록 내보내기**: 요약·활동 기록·해석 점검 3시트 엑셀. 기간·범위를 고를 수 있다.

## 1학기 도구와 다른 점 (저장소 규칙의 예외)

이 앱은 서버(Supabase)·DB·로그인을 쓰고 명렬표(학번·이름)와 풀이 기록을 저장한다. 저장소의 "개인정보를 저장하지 않는다"
규칙의 **명시적 예외**다(`CLAUDE.md` §4). 접근은 행 단위 권한으로 막혀 있다: 학생은 자기 기록만, 담당 교사는 담당 반만,
정답표는 제출 전에 누구도 읽지 못한다. 인터넷이 없는 교실에서는 쓸 수 없다.
